# 使用示例

此目录供用户学习、复制和修改，不参与桌宠程序的编译或运行时加载。

| 示例 | 用途 |
|---|---|
| [character-pack](character-pack/) | 完整的小猫角色包，包含 manifest、透明图片及素材许可；将目录内文件压到 ZIP 根目录，即可从角色管理窗口导入 |

示例使用独立 id `custom-cat-example`，与内置小猫区分。分享修改后的素材时保留或补充实际许可和来源说明。

主程序的内置角色资源位于 `src/CutePet.Desktop/Characters/Packs/`；个人导入的包位于 `%LOCALAPPDATA%\CutePet\Characters\`。完整制作步骤见 [角色包说明](../docs/character-packs.md)。
