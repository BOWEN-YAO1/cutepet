# 王座动作衔接（0.12.0）

日期：2026-10-02。这一版先调整「坐下—坐稳—起身」，没有全面重做挥手和乘云。

## 体验

退出旧桌宠，完整解压新版并启动 CutePet.exe，选择内置「洛天依（同人）」。右键或托盘 →「召唤王座 / 坐下休息」。动作管理中也可以分别播放召唤王座和起身。

新增准备、轻微屈膝下降、接近落座三张过渡帧，沿用现有最终坐姿、站姿、脸和服装。召唤 / 坐下从 5 帧增加到 8 帧，起身从 5 帧增加到 9 帧；仍为约 1.5 秒与 1 秒。中间移动阶段每帧约 80–110 毫秒，最终坐姿保持 320 毫秒用于停稳；起身先保留当前坐姿 160 毫秒再反向经过中间姿势。

坐下过程中点击或选择起身，会查找起身动作中与当前画面相同的帧，并按该帧内的进度反向开始，避免直接跳到半坐姿。重复点击不重启起身，只保留最近一次回应，起身完成后再挥手 / 开心回应。拖动、隐藏、换角色或新鲜低额度仍可以立即清理动作，保证用户接管及时。

自动休息、手动休息、乘云开关和额度显示保留。旧自定义天依不会自动更新，需要切换回内置角色，或导入新的独立变体。

## 角色包与兼容

没有新增动作名或改变 formatVersion: 1。角色作者可以在 conjure 和 stand 中引用同一套图片，起身时以相反次序组织；程序按已缓存图片的身份匹配当前姿势，前后方向的单帧持续时间可以不同。如果旧包没有匹配的起身姿势，会先完成当前坐下动作再起身，避免中途换到不相关的画面；没有起身动作时完成坐下后直接返回或回应。

总解码像素上限从 25,165,824 调整为 33,554,432，为新增过渡素材留出空间；云层也计入上限，仍限制单张 PNG 8 MiB / 2048 像素边长、最多 120 帧引用及 ZIP 64 MiB。内置天依现在为 17 张人物 PNG 加 1 张云层，共 28,294,818 像素。原素材保留，新图为版本文件。高分辨率素材的内存占用有所增加。

## 验证与预览

自动验证覆盖每一坐下阶段反向起身时保持同一张图片、不同前后单帧时长的映射、完整坐姿起身、没有匹配帧 / 没有起身动作的旧包、连续点击最新回应、重置 / 低额度清理、主窗口点击与实际 WPF 帧时钟。原有角色包、窗口、乘云和额度协议检查继续保留。

本版 307 项 WPF / 功能检查、14 项额度协议测试通过；GIF 的 19 帧及 4.4 秒总时间、循环与逐帧延迟已检查。

动画预览从真实 WPF 主窗口逐帧录制，使用同样的配置和时间，GIF 显示模拟额度 5h 72% / 周 48%，循环包含召唤、坐下、停留、起身。仅修补 GIF 的帧延迟与循环元数据，不修改生成素材。验证使用隔离设置和屏幕外窗口，不操作用户桌宠。

这仍是逐帧动画，加入中间姿势和按进度反向衔接能减少跳变，但没有骨骼变形或视频插帧。大尺寸下仍可能看到手绘细节、布料和脸部的帧间差异，需要用户实际试用判断。素材使用内置 image_gen.imagegen 编辑，完整提示词见角色包 REST-SMOOTH-PROMPTS.md 与 SOURCE.md。
