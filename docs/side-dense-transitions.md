# 侧边密集过渡（0.44.0）

上一版的32级探出仍有较明显的跨姿势跳跃。本版补绘112张透明过渡图，与旧32张交错为144级探出；点头、轻摇各保留16张独立姿势。侧边共有176张不同绘图，重复播放、倒放和运行时混合不计为新绘图。全角色354个不同绘图、28个动作、1720次帧引用、26个活跃PNG。

## 接入与播放

七张新增图集为 `side-transition-1-v9.png` 至 `side-transition-6-v9.png`、`side-transition-deep-v9.png`，均为1024×1536的4×4透明图集。使用内置imagegen生成，原PNG直接复制，保留alpha。前六张的实际进度覆盖范围未严格遵守提示，因此登记时测量可见虹膜距固定扶边点的距离，按实际露出程度交错。末段仍有较大跨度，追加第七张，以实际WPF深探出起止画面为参考。完整提示词见 [生成提示词](side-dense-prompts-v044.md)，原文件对应关系见角色包SOURCE.md。

登记画布288×384、双手平均扶边点(48,260)，头部目标高198像素，额头玉花用于平滑配准。头部尺寸测量包含对角相连的肤色像素，避免缩放过滤把上、下脸颊误判成两个独立区域。`tools/register-tianyi-side.py`只读源像素并写裁切、画布、锚点和时间配置。`tools/calibrate-tianyi-side.py`可读取当前配置对应的实际WPF登记预览，把尺度校准写入 `side-registration-v9.json`；不会改PNG，校准后需要重新登记、构建和验证。不要使用不对应当前配置的旧预览校准。

探出源图每张10毫秒，原点头、轻摇图每张40毫秒。完整探出往返2.87秒，缩回再探出4.31秒，探出加点头或轻摇各4.11秒。点头和轻摇在最匹配的实际探出阶段插入，然后继续探出；起止为相同待机图，缩回完全沿原序倒放。左右共用图片并镜像，扶边绘图不会再叠加整个人物的程序摆动，额度窗口继续固定。

144是不同姿势数量，不是显示器帧率。实际屏幕刷新按经过的时间采样并平滑连接相邻图，慢一帧不会把所有旧帧排队播放。新增姿势细化了露出程度，发丝、衣褶仍有源绘图差异；需要结合实际桌面播放继续验收，不能仅凭数量保证人眼完全看不到变化。

## 资源边界与兼容性

新包需要0.44.0；旧包继续兼容。仅登记并启用smoothFrames的左右贴边帧可使用10毫秒时间；普通动作和其他方向仍最低40毫秒。每包最多2048次引用、配置1 MiB，原图/不同裁切区域/登记画布共享100,663,296像素（384 MiB BGRA）预算。单图8 MiB、2048边长、单动作30秒、ZIP及解压后64 MiB、256条目和说明64 KiB保持。所有重复图共享缓存；预算不是应用总内存，本版的更多绘图会增加加载内存。

## 验证与预览

隔离验证加载实际176张侧边画面，检查不同像素哈希、头部大小、两个扶边手掌、固定锚点、144级原路倒放、起止相同画面、动作时间、左右镜像、菜单暂停、快速重复点击、工作区域变化、低额度退出和真实角色包导入/导出。10毫秒时间下限、未登记动作拒绝短帧、配置/引用/素材预算仍有边界验证。

`side-144-stages.png`展示全部144张实际登记的探出图。`side-drawn-keyframes.gif`按50 fps采样原绘图，避免GIF查看器把10毫秒延时误当100毫秒；`side-edge-actions.gif`展示左右窗口实际渲染，检查步长20毫秒、导出步长40毫秒。它们是预览，不作为新增源绘图计数。

最终素材通过14项核心检查与2466项隔离窗口检查；实际176张登记画面的头部尺寸范围为195–200像素。144级探出相邻露出距离最大4.919像素，登记脚本限制为最多5像素。当前保守素材计数97,887,485像素（373.41 MiB），在384 MiB预算内。
