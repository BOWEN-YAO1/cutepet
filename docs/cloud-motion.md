# 轻盈乘云（0.28.0）

日期：2026-10-03。改善原先直线搬动人物、云层单独轻晃的观感。沿用现有人物和云图，不增加图片、窗口、计时器或额度会话。

## 体验

退出旧版，完整解压新版并启动 CutePet.exe，选择内置「洛天依（同人）」，解锁位置。右键人物、额度或托盘，选择「乘云去逛逛」，随后把鼠标移开。开启「自由乘云活动」后，待机约 18 秒也会自动出发。附带的「洛天依（轻盈乘云）」角色包使用相同素材，可另行导入选择；已有带 cloud 的角色包同样使用新版运动。

巡游目的地仍在当前显示器工作区内，路线增加轻微弧度。人物先施法，云淡入、平滑抬升，随后缓缓加速；接近目的地时减速，人物姿态先回稳，再让云淡出落下。人物不翻转，额度条保持独立固定。

人物按约 5.3 秒的主要节奏起伏，叠加更慢的小幅变化，总幅度最多约 2.55 个逻辑像素。倾身随当前行进方向缓慢变化，叠加轻晃，总角度不超过 ±1.8°。云按稍晚的节奏起伏并小幅倾斜，宽高以相反方向最多变化 2.5%，人物不拉伸。浮动姿态用约 0.9 秒进入，抵达前约 1.2 秒回稳。途中约 4.2 秒尝试一次已有眨眼动作，结束后继续原路线；没有加入随机挥手或张望切帧。

鼠标靠近、悬停额度、显示详情、按住鼠标或打开菜单时，路线、起伏、倾身、云形变化和眨眼一起暂停，不累计暂停时间。位置锁定、拖动、低额度、隐藏、换角色、休息、改变人物大小等继续沿用取消规则，取消后全部新变换归零，随后可正常坐王座或贴边荡秋千。屏幕变化和额度盖住目的地的处理见 [桌面巡游](desktop-roaming.md)。

## 实现

- CloudFlight 使用五次平滑插值，使出发和到达的速度、加速度趋于零；同时计算人物起伏、方向倾身及云层的延迟起伏、倾斜和形变。姿态进入与回稳使用独立包络。
- RoamingRoute 提供三次贝塞尔曲线位置和方向。两个控制点与起点、终点都约束在整个人物窗口可用的范围内，利用曲线的凸包性质保持全路线不越界；负坐标、多屏 DPI 与任务栏仍按实际窗口像素计算。弧线偏移最多 48 DIP，或行程长度的 12%。
- 巡游时长把五次插值的 1.875 峰值及曲线最大导数上界计入原有约 40 DIP/秒峰值目标，仍限制为 8–120 秒。超大屏幕、极长行程受 120 秒上限限制，不能保证始终低于该速度目标。
- CloudMotionController 在既有角色帧时钟上应用各独立变换。CharacterPresenter 在巡游期间调用角色包已有 blink 动作，不解码新图片。CloudLean / CloudCharacterBob 仅属于人物图，CloudRoll / CloudBreath / CloudBob 仅属于云图，CloudLift 是共同抬升。

角色包格式仍为 1，无新增必填字段。当前内置天依仍为 28 张实际使用 PNG、44,013,894 解码像素，沿用 44,040,192 像素上限。小猫没有 cloud，保持原有行为。头发、裙摆、双脚和云上坐姿尚未独立动画；目前改善的是整体乘云运动，并未把整张人物素材拆成骨骼层。
