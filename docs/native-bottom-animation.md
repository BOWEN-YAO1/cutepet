# 下侧托腮连续动画（0.48.0）

内置天依的下侧抬头、左右张望和闭眼歪头改为连续网格运动。基础托腮姿态保持不变，双手与头部一起微动，影响逐渐在前臂消失；袖口底部的支撑带完全固定，继续贴在Windows工作区下边缘，即普通任务栏的上沿。自动隐藏任务栏继续沿用原有揭示条避让。额度在独立窗口，不跟着人物动作移动。

## 呈现与衔接

下侧共用一张256×352的睁眼托腮图集视图，不切换整张人物图片。既有图集中的闭眼视图在运行时裁切，两个眼部区域带3像素柔化边缘，随头部变形；闭眼过程中底图眼睛逐渐压缩，眼睑透明度连续变化。没有新增PNG或离线帧序列。

共享NativeAnimationView的32列、72行网格，共2409个人物顶点、4608个三角形；眼部另有8个顶点和4个三角形。三次Hermite曲线按经过时间采样，动作起止位移与速度为零；同一姿态重复呈现时复用网格和材质。菜单暂停冻结头部和眼睑，忙碌时点击不排队，工作区变化保留当前动作；脱离、隐藏、切换角色和低额度沿用既有中止规则。

抬头约1.56秒、张望约2.6秒、歪头闭眼约1.8秒，留出转动与回落时间。桌宠的原生网格随屏幕刷新更新，主界面角色页复用144×192透明预览表面，上限30fps。导出GIF仅供查看，为25fps，不作为运行素材。设备、透明窗口与WPF合成会影响实际帧率。

## 角色包格式

可选 `bottomAnimation` 包含：

- `headPivotX/Y`：头部支点比例坐标；x为0.3–0.7，y为0.55–0.8，且在袖口支撑点上方至少0.12。
- `closedEyesImage`：本地PNG路径。可选 `closedEyesRegion` 为图集像素矩形；取区后须与基础动作画布一致。图层和取区均受既有路径安全及384MiB总解码预算限制。
- `eyes`：两个依次排列、不重叠的眼部像素矩形，完整位于头部支点上方；每眼至少8×8像素，宽不超过画布25%、高不超过16%。
- `clips`：下侧回应的2–32个控制点；`at`严格递增覆盖0–1，`peek`横移为−6至6像素，`lift`上下移为−5至5像素，`angle`为−4至4度，`sway`为−2至2，`blink`为0–1。首尾各项运动为0。

基础与所有下侧回应必须各只有一帧、同一个裁切底图和袖口锚点，并关闭 `smoothFrames`；支撑点 `edgeAnchorY` 至少为0.85。动作曲线必须齐全。非法取区、眼部区域、曲线、移动锚点或混合底图均拒绝加载。缺少此字段的旧角色包继续按原序列播放，新的天依包需要0.48.0。

源图和登记来源见角色包SOURCE.md。旧下侧过渡图集保留在源码，当前应用与角色导出不再携带。其余乘云、站立和王座仍使用已有序列方式。

## 验证与限制

`CutePet.exe --verify-bottom-animation <新目录>` 检查真实透明绘制、单底图稳定、闭眼效果、支撑带固定、60Hz采样无网格折叠、起止像素一致、相机大小与上下/侧边切换。专门验证30项通过：眼部绿色虹膜像素由309降至3，60Hz相邻顶点最大移动约1.084源像素。这验证连续变形，不能保证所有电脑恒定60fps。

`--verify-bottom-window <新目录>` 检查真实窗口的固定接触线、菜单暂停、反复点击、工作区变化及额度位置；`--verify` 包含角色包导入导出、恶意配置拒绝、主界面预览、任务栏与自动隐藏避让、独立大小及其他方向回归。验证不会修改用户设置或关闭正在使用的桌宠。

当前沿用既有立绘进行轻量网格变形，尚未完整拆分头发、嘴型、手臂和服装；不能自动为任意立绘生成骨骼模型。多屏、实际任务栏和长期交互仍需桌面体验。
