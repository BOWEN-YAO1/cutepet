# 人物与额度独立窗口（0.14.0）

日期：2026-10-02。人物和额度现在属于同一应用中的两个透明小窗口，各自保存位置，共享一个额度模型、同步会话、设置文件和托盘。

## 使用

退出旧版，完整解压新版后启动 CutePet.exe。人物乘云移动或被拖动时，额度留在原处；拖额度可将它放在任意桌面位置，松开保存，不再自动吸附人物。拖动过程中按 Esc 或开启位置锁定会回到原位置。拖额度不清除人物的坐姿，人物拖动继续中断当前动作。

悬停额度条展开详情，移入详情继续查看。悬停人物只暂停 / 触发人物交互，不再从人物旁边打开额度详情。固定显示 / 隐藏详情继续保留。角色和额度数字大小分别只改变各自窗口；两个窗口都能右键打开同一套菜单。

「额度条位置」上 / 下 / 左 / 右现在是一次性的摆放操作：把额度放到人物该方向，并选择横排或竖排；之后人物移动不会带走它。「移回屏幕右下角」重新摆放人物及附近额度。两个窗口一起置顶、隐藏、从托盘恢复和退出，不会新增任务栏按钮或额度查询。

旧 Left / Top 表示组合窗口左上角。首次启动新版时按原布局、大小和当前 DPI 推导人物与额度各自的位置，标记 IndependentWindows，避免重复转换。新设置增加 QuotaLeft / QuotaTop，均保存物理桌面像素；保留其他设置、现有账号和角色包。显示器改变或位置超出可用区域时分别约束到可见范围。

## 当前范围

本版完成窗口拆分，人物仍沿用约 96 DIP 的短距离乘云及自动开关；尚未实现整个桌面的随机巡游、跨屏巡游、跟随额度开关或召回动作。这些可以在独立窗口基础上继续开发。

## 实现入口

- Views/MainWindow.xaml / .cs：人物窗口、一个额度会话及应用生命周期协调。
- Views/QuotaWindow.xaml / .cs：额度与详情、独立拖动、取消、缩放和位置。
- Layout/SplitWindowLayout.cs：人物尺寸、一次性相对摆放及旧位置迁移；DockLayout 保留原布局几何用于迁移。
- Settings/Preferences.cs：独立额度坐标与迁移标记。
- Views/Controllers/CloudMotionController.cs：移动人物窗口；不移动额度窗口。
- Verification/SplitWindowVerification.cs / WindowPreview.cs：两窗口行为、真实 HWND 生命周期与预览。

## 验证

376 项窗口 / 功能检查及 14 项额度协议测试通过。覆盖两枚独立 HWND、共享额度模型、详情锚定、四方向旧位置迁移和 DPI、迁移只执行一次、独立拖动保存与取消、锁定、两种缩放、乘云不移动额度、置顶、实际隐藏 / 恢复和退出销毁额度窗口。

验证使用隔离设置、屏幕外位置与零透明度，不操作用户桌宠、登录或开机启动项。预览由两个实际 WPF 内容树合成，在验证器计算的横向位置绘制人物、固定绘制额度；不是用户桌面的录屏。GIF 共 41 帧，每帧 200 毫秒，8.2 秒循环。

真实鼠标捕获、跨显示器 DPI 切换、长期运行和多个前台应用之间的置顶关系仍需桌面试用验收。
