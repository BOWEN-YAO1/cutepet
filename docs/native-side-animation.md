# 原生连续侧边动画（0.46.0）

将人物绘图拼成GIF或视频并不能消除原绘图的比例与细节差异。本次先验证单张透明贴图＋网格连续变形：天依左右侧边四个回应由时间曲线驱动，不再逐张换画面。上侧、下侧、乘云和坐姿仍沿用原播放方式。

## 实现与使用

SideAnimationView 采用WPF Viewport3D，固定一张288×384纹理、325个顶点、576个三角形。运动在屏幕刷新时按已过去的时间采样，使用保持形状的三次Hermite曲线，起止速度为零。双手区域固定，头部和衣摆使用连续权重移动。左右镜像，额度窗口保持独立。暂停时不更新网格，同姿势无需重复更新。切换角色释放纹理与网格。顶点集合双缓冲，修改时暂时从场景分离；纹理材质冻结。

这不是视频播放或Live2D模型；暂不含拆层眨眼、嘴型、独立发丝或大幅肢体运动。固定纹理减少跨绘图变化，实际帧率仍取决于设备、WPF合成和窗口环境，不能保证所有电脑恒定60fps。后续若效果合适，可拆分头、躯干、手臂、发丝、裙摆，制作完整骨骼角色，再迁移其他动作。

选择内置天依，在左右侧边点击或悬停体验；旧导入角色不会自动更新。角色页播放侧边动作使用相同运动曲线与网格，离屏绘制到一张可复用的144×192透明预览表面，预览限制30fps。主界面滚动容器直接嵌入三维层的隔离截图出现空白，因此采用此兼容呈现路径；桌宠侧边仍由原生网格直接绘制。预览GIF不作为程序播放资源。

## 角色包字段

可选 `sideAnimation` 包含 `idleOffsetX`、`headPivotX/Y` 和 `clips`。每个回应使用2–32个控制点，`at`递增并覆盖0至1；`peek`、`lift`、`angle`、`sway`分别控制探出位移、上下位移、角度与身体轻摆。位移以贴图像素计，角度为度。支点为比例坐标。默认模型的固定手掌权重针对当前登记姿势；此试验格式不能自动适配任意角色图片。

所有侧边动作必须共用同一图片、裁切/画布、手掌锚点，每个动作仅一帧且关闭 `smoothFrames`。曲线首尾全部运动为零。idleOffsetX范围−48至0，头支点x范围0.25–0.8、y范围0.35–0.65；peek范围−16至40，lift范围−8至8，angle范围−6至6，sway范围−4至4。校验器拒绝混合序列、缺失曲线、非递增时间、不合法数值和无法回归的终点。

## 验证

独立 `--verify-side-animation` 检查真实透明渲染、固定双手、连续60Hz采样、单纹理、网格无折叠、起止像素一致和角色切换清理，并生成动作预览。完整 `--verify` 还检查预览实际非透明像素与复用表面、左右边缘对齐、菜单暂停、重复点击、额度位置、主界面预览及角色包导入导出。`--benchmark-animation` 仅测CPU网格更新时间，不能当作实际屏幕帧率。

本机Release版本的926次CPU网格更新测量：平均0.066毫秒、p95为0.079毫秒、最大6.887毫秒，总线程分配约0.221 MiB。该测量不含WPF合成和实际显示，不能用来承诺屏幕60fps。独立动画验证31项通过，60Hz采样中探出位移相邻最大变化1.266源像素。
