# 桌面乘云巡游（0.15.0）

**0.28.0 更新**：下文保留初版记录。当前巡游路线改为轻微弧线，加入人物和云独立运动、五次平滑加减速及途中眨眼；时长计入曲线导数，范围与交互规则继续适用。详见 [轻盈乘云](cloud-motion.md)。

日期：2026-10-02。人物可以在当前显示器的可用区域内乘云移动，额度仍独立固定。只移动小型人物窗口，没有全屏透明遮罩，不增加额度会话。

## 使用

退出旧版，完整解压并启动新版 CutePet.exe，选择内置「洛天依（同人）」。

- 右键人物、额度或托盘 →「乘云去逛逛」：手动选择当前屏幕上的随机目的地，施法后出发。
- 「自由乘云活动」开关：待机约 18 秒后尝试一次巡游，到达后停留再计划下一次；复用旧 AutoCloud 设置并保存。旧版关闭自动乘云的用户，需要手动打开这个开关。
- 「召回到额度旁」：结束当前乘云或王座动作，立即把人物放回额度旁边，额度不动。召回后至少等候 18 秒才自动再次出发；不自动关闭自由活动开关。小猫也可召回。
- 锁定位置会取消并禁止巡游；显式召回仍可执行，锁定保持。关闭自由活动取消当前移动，手动「乘云去逛逛」仍可用。

角色必须提供独立云图层才能巡游，小猫不新增乘云动作。所有内置 / 自定义角色原有坐姿、表情、大小和额度功能保留，角色包格式仍为 1，素材没有更新。

## 活动与交互

目的地使用当前显示器 WorkingArea，避开任务栏，计算整个人物窗口的实际像素大小和 DPI。随机点可以覆盖该屏幕的横向与纵向范围；整条直线路径以缓入缓出速度移动，不越过该屏幕边界。目标位置避开额度面板及约 12 DIP 间距；路径中途仍可能经过额度附近。

移动沿用施法、云出现 / 升起、行进、云消失 / 落稳流程。根据距离规划时长，通常以约 40 DIP / 秒峰值为目标，行进限制为 8–120 秒；到达后停留，再选择新目的地。自动坐下休息会在停留期间继续工作，坐着时不出发。

鼠标靠近人物、悬停额度、查看详情、按住鼠标或打开菜单时暂停，恢复时继续原路线，不累计暂停时间。拖人物、拖额度、隐藏、换角色、低额度或人物大小变化会取消当前移动。屏幕工作区 / 人物实际像素尺寸改变，或新额度大小 / 位置盖住目的地时，也取消该路线；屏幕变化时重新约束人物位置。

本版不自动跨屏。把人物拖到另一显示器后，下一次巡游在该显示器规划；召回依据额度所在显示器，因此显式召回可以把人物移到额度所在屏幕。没有增加行走、朝向翻转、窗口边缘攀爬或前台应用避让。

## 实现

Characters/DesktopRoaming.cs 规划受边界约束的随机目的地、距离与时长、召回位置；Characters/CloudFlight.cs 支持可变行进时长；CloudMotionController 使用同一帧时钟计算两个方向的坐标，只移动人物窗口。NativePlacement.RoamingBounds 获取当前屏幕工作区和真实窗口像素大小。两处菜单共用主窗口指令，AutoCloud 保持兼容。
