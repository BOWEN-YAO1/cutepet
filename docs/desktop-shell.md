# 角色包、自定义角色与桌宠额度显示（开发原型 0.10.0）

日期：2026-10-02。此版本保留小猫和洛天依同人角色，保留位置锁定、开机启动开关与角色帧动画，并将素材与动作配置整理为独立角色包，加入自定义角色管理。额度条默认位于角色左侧偏下，可拖动切换四个方向，通过悬停展开详情。0.2.0 的五项基础功能已由用户试用反馈正常；新增交互、系统登录启动与动画实际体验仍需人工桌面验收，Releases 分发尚未完成。

## 使用与日常启动

1. 保持兼容的官方原生 Codex CLI 已安装，并先在官方 Codex 中通过 ChatGPT 登录。本机已验证 CLI 0.159.2。
2. 开发便携包需要 [.NET 8 Desktop Runtime，Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)。已有包含此运行环境的 .NET SDK 时无需重复安装。仅有普通 .NET Runtime 不足以运行 WPF 窗口。
3. 升级前先从托盘退出旧版，再解压整个 ZIP 到固定文件夹，双击 `CutePet.exe`。保留同目录的 DLL 和配置文件。日常可为 EXE 创建桌面快捷方式。已有实例运行时，再次启动只唤起旧实例。
4. 程序使用已有官方登录读取额度。未找到 CLI 时右键选择原生 `codex.exe`，保存后退出、重新启动。路径选择只影响下次启动，当前连接继续使用原路径。不支持 `.cmd` / `.ps1` 启动器。
5. 未登录时先在官方 Codex 登录再刷新；API key 的账单不作为订阅额度显示。

当前包不自包含运行环境，不自动安装依赖、不自动登录。源码运行需要 Windows + .NET 8 SDK：

```powershell
dotnet build CutePet.sln -c Release
dotnet run --project src/CutePet.Desktop -c Release --no-build
```

## 窗口操作

| 操作 | 结果 |
|---|---|
| 拖动角色 | 移动整个窗口，松开后保存位置 |
| 拖动额度条空白处 | 调整相对角色的方向，显示停靠预览，松开吸附并保存 |
| 额度条拖动时按 Esc | 取消操作，恢复原方向；丢失鼠标捕获也取消 |
| 右键或托盘「额度条位置」 | 选择上方、下方、左侧、右侧，重启保留 |
| 右键或托盘「角色选择」 | 切换内置和已导入角色，立即生效、重启保留 |
| 右键或托盘「管理 / 导入角色…」 | 预览、导入 PNG / ZIP、使用、导出和移除归档 |
| 右键或托盘「角色大小」 | 80%–200%，只改变角色和其气泡，不改变额度数字 |
| 右键或托盘「额度数字大小」 | 80%–200%，改变数字、短标签和适配的额度底板，不改变角色 |
| 右键或托盘「锁定位置」 | 禁止拖角色和额度条，取消勾选解锁，重启保留 |
| 右键或托盘「开机启动」 | 注册 / 移除当前用户的 CutePet 登录启动项，默认关闭 |
| 单击角色 | 洛天依短暂挥手，小猫轻摇并眨眼，保留文字回应 |
| 悬停角色或额度条 | 350 毫秒后显示详情，移开 650 毫秒后收起 |
| 鼠标从角色移入详情 | 保持详情显示，可滚动、刷新、固定和收起 |
| 详情「刷新」 | 排队读取官方额度，遵循最短间隔 |
| 详情「固定 / 取消固定」 | 在固定显示与悬停显示之间切换 |
| 详情「收起」 | 关闭浮层并回到悬停模式；再次移入角色可重新展开 |
| 右键桌宠或额度条 | 角色选择、置顶、大小、详情显示、位置恢复、路径选择、隐藏、退出 |
| 右键或托盘「隐藏桌宠」 | 隐藏角色和详情，额度同步继续，动画暂停 |
| 双击托盘图标 | 恢复窗口 |
| 再次启动程序 | 通知已有实例显示窗口 |
| 托盘或右键「退出」 | 取消同步，停止本程序拥有的后台进程，保存设置并退出 |

默认透明、无边框、置顶，位于主屏右下角，不占任务栏。位置以物理像素保存，恢复时按当前显示器工作区检查；失去原显示器时移回可见区域。原生拖动、多显示器和 DPI 切换需按下表人工验收。

## 关键信息与详情开关

默认左右停靠时主窗口为 352 × 184 DIP（100% 大小），额度条为 116 × 68 DIP，采用竖排；上方停靠时为 280 × 236 DIP，下方为 280 × 234 DIP，额度条为 224 × 40 DIP，采用横排。百分比字号从 12 增为 23，标签从 10 增为 13；角色绘制尺寸保持原值。正常状态隐藏常驻对话气泡，点击、低额度、连接异常时才显示回应。

0.6.0 将原「桌宠大小」拆成「角色大小」与「额度数字大小」，右键和托盘都提供 80%、100%、120%、140%、160%、180%、200% 七档。两项各自保存；切换角色不重置大小。数字字号为 23 × 数字比例，标签、留白和底板同比适配，避免大数字被裁切；角色、气泡、阴影随角色比例变化。四方向主窗口和拖动工作区根据两种大小动态计算。调整尽量保留角色屏幕位置，空间不足时移回工作区。

悬停详情大小沿用旧偏好，独立调整不使其跟随放大。新配置详情采用原有 348 × 256 DIP。旧版 Scale 值继续保留用于兼容；缺少 CharacterScale / QuotaScale 时，各自继承经校验的旧 Scale，因此原来 120% 的用户升级后两项仍是 120%。新大小有限值范围为 0.8–2，无效值恢复 1；无需清除配置。

## 位置锁定与开机启动

锁定只禁止鼠标拖动角色和额度条；悬停、点击回应、右键和托盘仍可用。锁定中的额度拖动会取消并恢复原停靠。显式菜单操作仍可调整大小、切换停靠或移回屏幕，避免把桌宠锁在不可见位置。系统工作区变化也仍可修正位置。

开机启动默认关闭。启用时只写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `CutePet` 字符串值，命令为带双引号的当前 `CutePet.exe` 完整路径，加 `--autostart` 参数。禁用只删除这一值，退出桌宠不会删除。实际含义是当前用户登录 Windows 时启动，系统可能延迟执行。[微软 Run 键说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)

开关读实际注册值，写入失败提示错误并保持实际状态；启用前检查 EXE 存在，拒绝引号、控制字符和超过 260 字符的命令。未启用时不写注册表。已启用的便携目录移动或升级后，手动运行新版会更新自己的 EXE 路径；升级先退出旧实例。外部删除启动条目后，刷新菜单只读状态，不重新创建。Windows 启动应用设置或系统策略也可能影响实际执行，本版不修改它们。

自动模式与手动模式使用相同单实例流程，登录启动后显示桌宠。开关只影响 CutePet，不启动、停止或修改其他 Codex 客户端。

额度条可吸附到四个预设位置，本版不保存任意自由偏移。拖动越过最小距离后临时扩大透明工作区，绿色轮廓与文字提示松开后的方向；拖动期间关闭详情。切换布局尽量保持角色的屏幕位置，若新布局超出显示器工作区，则整体移回可见区域。0.5.1 移除额度条菜单按钮，设置仍可通过右键或托盘访问。

紧凑额度条只显示前两个实际返回窗口的短标签和百分比，例如「5h 72%」「周 48%」。状态行、状态点、进度条、额外窗口计数和菜单按钮全部移除；全部窗口、完整额度桶名称、重置时间和同步状态通过详情查看。缺失数据和同步失败显示「—」；详情保留上次数据并明确标注。成功同步后简略百分比恢复。隐藏详情模式也保留现有低额度与连接气泡，右键可恢复详情。预览图使用演示额度。

右键和托盘菜单的「详情显示」提供三个互斥选项：

| 模式 | 行为 |
|---|---|
| 悬停显示（默认） | 角色或额度条悬停 350 毫秒展开；离开角色和详情 650 毫秒后收起 |
| 固定显示 | 持续显示详情，鼠标离开仍保留；可以点击「取消固定」或「收起」 |
| 隐藏详情 | 悬停不展开，只显示角色与关键信息；随时从右键或托盘恢复 |

详情采用独立浮层，展开不调整角色主窗口大小和位置。左右停靠时优先显示在对应一侧，上下停靠时优先显示在主窗口上方；边缘位置由 WPF Popup 进行调整。真实屏幕边缘与多屏行为仍须人工验证。[WPF 浮层定位说明](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/popup-placement-behavior)

开合使用延迟，快速划过会取消展开，从角色移到详情会取消收起；右键菜单打开时暂停自动收起。拖动期间关闭浮层，松开后按当前模式恢复。隐藏桌宠时一并关闭浮层，托盘恢复后固定模式自动恢复详情。

## 额度与角色状态

所有真实数据来自现有 `CutePet.Codex` 模块，经官方 CLI 的独立 App Server 读取，不运行模型任务。按实际返回的额度窗口生成行；缺少比例显示「—」，不会补成 0%。多额度桶时可滚动查看，较长名称省略并提供悬浮提示。

启动立即查询，正常每 60 秒刷新。通知和手动刷新合并到容量为 1 的队列，同一时刻只执行一轮读取；两轮间最少等待 10 秒。失败按 60 / 120 / 240 / 300 秒退避，手动刷新可提前触发。

超时或服务错误保留内存中的上次数据，并明确显示「未同步 · 当前为上次数据」。身份、认证、协议或连接失败清空显示，避免展示可能不属于当前账号的额度；账号通知也立即清空。此版本不将额度落盘，不提供持久缓存。

倒计时每 30 秒更新。归零显示「等待官方额度更新」，等待后续查询确认，不自行填为 100%。系统时间影响倒计时显示。后台连接是否及时感知其他客户端或设备的账号切换，仍以 [接入验证记录](codex-integration-validation.md) 中的边界为准。

两种角色支持轻微上下移动，待机每 4 秒眨眼。洛天依以透明闭眼帧显示约 160 毫秒；正常待机时每隔随机 8–16 秒尝试左右张望；点击随机多姿态挥手（约 1.12 秒）或开心回应（0.9 秒），随后回到当前额度状态。小猫使用由原矢量导出的透明帧眨眼和点击轻摇。正常状态不常驻气泡。有效且新鲜的额度剩余低于 20% 时，洛天依使用疲惫表情、小猫眯眼，保留气泡与橙色额度提示；数据过期时停止用旧额度驱动低额度表情。隐藏时暂停计时器、清除未完成动作，额度同步继续；换角色和退出也清理临时动作。当前不检测模型任务状态，不提供重置庆祝动画。

## 本地设置与素材

设置位于 `%LOCALAPPDATA%\CutePet\settings.json`，仅保存位置、大小、置顶、CLI 路径、详情模式、额度方向、角色、位置锁定与启动开关状态。启动实际状态以自己的系统条目为准，不单凭设置文件自动创建。旧配置缺少新开关时默认未锁定、未启用启动；其他偏好保留。通过临时文件替换写入；损坏设置回到默认，异常数值经过校验。拖动途中不保存临时工作区。不存令牌、账号标识和额度快照。清除设置不会移除系统启动项，移除前请先在菜单关闭开机启动。

小猫由仓库内 XAML 路径绘制，为本项目占位素材，按仓库 GPL v3 分发。参考视频中的角色未作为程序素材使用。

洛天依有九张透明同人 PNG，配置六种动作，均由内置 imagegen 生成或编辑，作为 WPF Resource 嵌入，加载时解码、冻结并缓存。单个交互覆盖上一交互，不排队累积；40 毫秒帧计时器按实际经过时间推进。多姿态挥手和表情仍为逐帧动画，并非骨骼或 Live2D 动画。切换不修改额度、大小、停靠、置顶和详情偏好。默认仍为小猫。来源、完整提示词和素材权利说明见 [角色素材记录](character-assets.md) 与 [素材说明](../THIRD_PARTY_NOTICES.md)。

## 打包

在 Windows x64 开发机上构建框架依赖的便携目录：

```powershell
dotnet publish src/CutePet.Desktop -c Release --self-contained false -o artifacts/CutePet-Desktop
```

随目录附上仓库 `LICENSE`、素材记录、本说明与对应源码提交链接，再压缩整个目录。当前没有自动 Release 和安装器。正式版携带运行环境的计划见 [开发文档](development.md)。
