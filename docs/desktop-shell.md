# 桌宠角色选择、额度条停靠与悬停详情（开发原型 0.5.0）

日期：2026-10-01。此版本保留原创矢量小猫，新增洛天依同人角色选项。额度条默认位于角色左侧偏下，可拖动切换四个方向，通过悬停展开详情。0.2.0 的五项基础功能已由用户试用反馈正常；新增交互仍需人工桌面验收。更多角色动作、完整验收和 Releases 分发尚未完成。

## 使用与日常启动

1. 保持兼容的官方原生 Codex CLI 已安装，并先在官方 Codex 中通过 ChatGPT 登录。本机已验证 CLI 0.159.2。
2. 开发便携包需要 [.NET 8 Desktop Runtime，Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)。已有包含此运行环境的 .NET SDK 时无需重复安装。仅有普通 .NET Runtime 不足以运行 WPF 窗口。
3. 升级前先从托盘退出旧版，再解压整个 ZIP 到固定文件夹，双击 `CutePet.exe`。保留同目录的 DLL 和配置文件。日常可为 EXE 创建桌面快捷方式。已有实例运行时，再次启动只唤起旧实例。
4. 程序使用已有官方登录读取额度。未找到 CLI 时右键选择原生 `codex.exe`，保存后退出、重新启动。路径选择只影响下次启动，当前连接继续使用原路径。不支持 `.cmd` / `.ps1` 启动器。
5. 未登录时先在官方 Codex 登录再刷新；API key 的账单不作为订阅额度显示。

当前包不自包含运行环境，不自动安装依赖、不自动登录。源码运行需要 Windows + .NET 8 SDK：

```powershell
dotnet build CutePet.sln -c Release
dotnet run --project src/CutePet.Desktop -c Release --no-build
```

## 窗口操作

| 操作 | 结果 |
|---|---|
| 拖动角色 | 移动整个窗口，松开后保存位置 |
| 拖动额度条空白处 | 调整相对角色的方向，显示停靠预览，松开吸附并保存 |
| 额度条拖动时按 Esc | 取消操作，恢复原方向；丢失鼠标捕获也取消 |
| 右键或托盘「额度条位置」 | 选择上方、下方、左侧、右侧，重启保留 |
| 右键或托盘「角色选择」 | 切换小猫 / 洛天依（同人），立即生效、重启保留 |
| 单击角色 | 短暂回应并眨眼 |
| 悬停角色或额度条 | 350 毫秒后显示详情，移开 650 毫秒后收起 |
| 鼠标从角色移入详情 | 保持详情显示，可滚动、刷新、固定和收起 |
| 详情「刷新」 | 排队读取官方额度，遵循最短间隔 |
| 详情「固定 / 取消固定」 | 在固定显示与悬停显示之间切换 |
| 详情「收起」 | 关闭浮层并回到悬停模式；再次移入角色可重新展开 |
| 右键或额度条「···」 | 置顶、大小、详情显示、位置恢复、路径选择、隐藏、退出 |
| 右键或托盘「隐藏桌宠」 | 隐藏角色和详情，额度同步继续，动画暂停 |
| 双击托盘图标 | 恢复窗口 |
| 再次启动程序 | 通知已有实例显示窗口 |
| 托盘或右键「退出」 | 取消同步，停止本程序拥有的后台进程，保存设置并退出 |

默认透明、无边框、置顶，位于主屏右下角，不占任务栏。位置以物理像素保存，恢复时按当前显示器工作区检查；失去原显示器时移回可见区域。原生拖动、多显示器和 DPI 切换需按下表人工验收。

## 关键信息与详情开关

默认左右停靠时主窗口为 396 × 192 DIP（100% 大小），额度条采用竖排；上下停靠时为 280 × 252 DIP，采用横排。角色绘制尺寸保持原值。正常状态隐藏常驻对话气泡，点击、低额度、连接异常时才显示回应。

额度条可吸附到四个预设位置，本版不保存任意自由偏移。拖动越过最小距离后临时扩大透明工作区，绿色轮廓与文字提示松开后的方向；拖动期间关闭详情。切换布局尽量保持角色的屏幕位置，若新布局超出显示器工作区，则整体移回可见区域。菜单按钮不启动额度条拖动。

紧凑额度条显示前两个实际返回的窗口，例如「5h 72%」「周 48%」，以及同步状态。多于两个窗口时显示「+数量」，在详情里查看全部；隐藏详情模式也保留低额度和旧数据提示。缺失数据依然为「—」，旧数据明确标注「上次数据」。

右键和托盘菜单的「详情显示」提供三个互斥选项：

| 模式 | 行为 |
|---|---|
| 悬停显示（默认） | 角色或额度条悬停 350 毫秒展开；离开角色和详情 650 毫秒后收起 |
| 固定显示 | 持续显示详情，鼠标离开仍保留；可以点击「取消固定」或「收起」 |
| 隐藏详情 | 悬停不展开，只显示角色与关键信息；随时从右键或托盘恢复 |

详情采用独立浮层，展开不调整角色主窗口大小和位置。左右停靠时优先显示在对应一侧，上下停靠时优先显示在主窗口上方；边缘位置由 WPF Popup 进行调整。真实屏幕边缘与多屏行为仍须人工验证。[WPF 浮层定位说明](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/popup-placement-behavior)

开合使用延迟，快速划过会取消展开，从角色移到详情会取消收起；右键菜单打开时暂停自动收起。拖动期间关闭浮层，松开后按当前模式恢复。隐藏桌宠时一并关闭浮层，托盘恢复后固定模式自动恢复详情。

## 额度与角色状态

所有真实数据来自现有 `CutePet.Codex` 模块，经官方 CLI 的独立 App Server 读取，不运行模型任务。按实际返回的额度窗口生成行；缺少比例显示「—」，不会补成 0%。多额度桶时可滚动查看，较长名称省略并提供悬浮提示。

启动立即查询，正常每 60 秒刷新。通知和手动刷新合并到容量为 1 的队列，同一时刻只执行一轮读取；两轮间最少等待 10 秒。失败按 60 / 120 / 240 / 300 秒退避，手动刷新可提前触发。

超时或服务错误保留内存中的上次数据，并明确显示「未同步 · 当前为上次数据」。身份、认证、协议或连接失败清空显示，避免展示可能不属于当前账号的额度；账号通知也立即清空。此版本不将额度落盘，不提供持久缓存。

倒计时每 30 秒更新。归零显示「等待官方额度更新」，等待后续查询确认，不自行填为 100%。系统时间影响倒计时显示。后台连接是否及时感知其他客户端或设备的账号切换，仍以 [接入验证记录](codex-integration-validation.md) 中的边界为准。

小猫支持轻微上下移动、每 4 秒眨眼、点击气泡回应。正常状态不常驻气泡。任一有效额度窗口剩余低于 20% 时气泡提示，进度条改为橙色；数据过期时气泡提示连接恢复。隐藏窗口暂停动画，继续查询。当前角色不检测模型任务状态，不提供疲惫表情或重置庆祝动画。

## 本地设置与素材

设置位于 `%LOCALAPPDATA%\CutePet\settings.json`，仅保存位置、大小、置顶、CLI 路径、详情模式、额度条方向与角色选择。通过临时文件替换写入；损坏设置回到默认，异常数值经过校验。旧设置缺少详情模式时默认悬停显示，缺少方向时默认左侧，缺少角色或角色值无效时采用小猫；其余设置保留，不要求删除设置。拖动途中不保存临时工作区。不存令牌、账号标识和额度快照。移除设置前退出桌宠即可恢复默认。

小猫由仓库内 XAML 路径绘制，为本项目占位素材，按仓库 GPL v3 分发。参考视频中的角色未作为程序素材使用。

洛天依同人图是本次通过内置 imagegen 生成的透明 PNG，作为 WPF Resource 嵌入，首次使用时加载并缓存，不依赖外部图片路径。两种角色共用轻微浮动、点击文字回应、低额度与连接状态气泡；本版洛天依为单帧，没有眨眼或单独的低额度表情动画。切换不修改额度、大小、停靠、置顶和详情偏好。默认仍为小猫，需主动从角色菜单选择洛天依。来源、完整提示词和素材权利说明见 [角色素材记录](character-assets.md) 与 [素材说明](../THIRD_PARTY_NOTICES.md)。

## 自动验证及已知边界

本机 Release 构建无警告、无错误；14 项协议测试通过，包含新增的账号失效事件检查。WPF 验证模式不显示桌面窗口、不创建托盘、不使用个人设置；生成真实界面渲染图和 JSON 检查报告：

```powershell
dotnet tests/CutePet.Tests/bin/Release/net8.0/CutePet.Tests.dll
dotnet src/CutePet.Desktop/bin/Release/net8.0-windows/CutePet.dll --verify artifacts/desktop-verification
```

0.4.0 的 45 项检查通过，保留 0.3.0 的 32 项检查，并新增四方向布局边界、拖动目标、取消恢复、拖动不误开详情、方向持久保存与旧设置兼容检查。悬停和拖动检查调用实际事件共用的状态处理函数，不移动真实鼠标，也不显示原生浮层。已检查四方向与拖动预览，以及紧凑视图的 100%、150%、200% 和详情的 100%、150% WPF 离屏渲染；这不等同于真实鼠标捕获、屏幕位置、显示器 DPI 切换或浮层定位测试。

0.5.0 合计 51 项检查通过，新增旧角色设置兼容、嵌入图片与缓存加载、透明背景、切换时保留显示和额度设置、重启恢复角色、切回原小猫检查。生成洛天依四方向预览及 140% 大小 / 200% 渲染图，人工查看角色与额度条布局。实际菜单点击、角色浮动和长期运行仍需桌面试用。

0.2.0 的真实账号模式已额外通过一次官方查询，把返回快照送入桌宠显示模型并生成预览，当时合计 18 项检查。0.3.0 至 0.5.0 未重复真实账号查询；额度接入实现未改动。真实模式只在维护者本机运行，不向 CI 添加账号或凭据：


## 打包

在 Windows x64 开发机上构建框架依赖的便携目录：

```powershell
dotnet publish src/CutePet.Desktop -c Release --self-contained false -o artifacts/CutePet-Desktop
```

随目录附上仓库 `LICENSE`、本说明与对应源码提交链接，再压缩整个目录。当前没有自动 Release、开机启动和安装器。正式版携带运行环境的计划见 [开发文档](development.md)。
