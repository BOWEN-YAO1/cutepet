# 第一版桌宠窗口（开发原型 0.2.0）

日期：2026-10-01。此版本把已有额度模块接到 WPF 桌面窗口，使用原创矢量小猫占位。正式角色素材、丰富动作、完整人工验收和 Releases 分发尚未完成。

## 使用与日常启动

1. 保持兼容的官方原生 Codex CLI 已安装，并先在官方 Codex 中通过 ChatGPT 登录。本机已验证 CLI 0.159.2。
2. 开发便携包需要 [.NET 8 Desktop Runtime，Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)。已有包含此运行环境的 .NET SDK 时无需重复安装。仅有普通 .NET Runtime 不足以运行 WPF 窗口。
3. 解压整个 ZIP 到固定文件夹，双击 `CutePet.exe`。保留同目录的 DLL 和配置文件。日常可为 EXE 创建桌面快捷方式。
4. 程序使用已有官方登录读取额度。未找到 CLI 时右键选择原生 `codex.exe`，保存后退出、重新启动。路径选择只影响下次启动，当前连接继续使用原路径。不支持 `.cmd` / `.ps1` 启动器。
5. 未登录时先在官方 Codex 登录再刷新；API key 的账单不作为订阅额度显示。

当前包不自包含运行环境，不自动安装依赖、不自动登录。源码运行需要 Windows + .NET 8 SDK：

```powershell
dotnet build CutePet.sln -c Release
dotnet run --project src/CutePet.Desktop -c Release --no-build
```

## 窗口操作

| 操作 | 结果 |
|---|---|
| 拖动角色或面板空白处 | 移动整个窗口，松开后保存位置 |
| 单击角色 | 短暂回应并眨眼 |
| 面板「刷新」 | 排队读取官方额度，遵循最短间隔 |
| 右键或面板「···」 | 置顶、80% / 100% / 120% / 140% 大小、位置恢复、路径选择、隐藏、退出 |
| 面板「−」 | 隐藏到托盘，额度同步继续，动画暂停 |
| 双击托盘图标 | 恢复窗口 |
| 再次启动程序 | 通知已有实例显示窗口 |
| 托盘或右键「退出」 | 取消同步，停止本程序拥有的后台进程，保存设置并退出 |

默认透明、无边框、置顶，位于主屏右下角，不占任务栏。位置以物理像素保存，恢复时按当前显示器工作区检查；失去原显示器时移回可见区域。原生拖动、多显示器和 DPI 切换需按下表人工验收。

## 额度与角色状态

所有真实数据来自现有 `CutePet.Codex` 模块，经官方 CLI 的独立 App Server 读取，不运行模型任务。按实际返回的额度窗口生成行；缺少比例显示「—」，不会补成 0%。多额度桶时可滚动查看，较长名称省略并提供悬浮提示。

启动立即查询，正常每 60 秒刷新。通知和手动刷新合并到容量为 1 的队列，同一时刻只执行一轮读取；两轮间最少等待 10 秒。失败按 60 / 120 / 240 / 300 秒退避，手动刷新可提前触发。

超时或服务错误保留内存中的上次数据，并明确显示「未同步 · 当前为上次数据」。身份、认证、协议或连接失败清空显示，避免展示可能不属于当前账号的额度；账号通知也立即清空。此版本不将额度落盘，不提供持久缓存。

倒计时每 30 秒更新。归零显示「等待官方额度更新」，等待后续查询确认，不自行填为 100%。系统时间影响倒计时显示。后台连接是否及时感知其他客户端或设备的账号切换，仍以 [接入验证记录](codex-integration-validation.md) 中的边界为准。

小猫支持轻微上下移动、每 4 秒眨眼、点击气泡回应。任一有效额度窗口剩余低于 20% 时气泡提示，进度条改为橙色；数据过期时气泡提示连接恢复。隐藏窗口暂停动画，继续查询。当前角色不检测模型任务状态，不提供疲惫表情或重置庆祝动画。

## 本地设置与素材

设置位于 `%LOCALAPPDATA%\CutePet\settings.json`，仅保存位置、大小、置顶与 CLI 路径。通过临时文件替换写入；损坏设置回到默认，异常数值经过校验。不存令牌、账号标识和额度快照。移除设置前退出桌宠即可恢复默认。

小猫由仓库内 XAML 路径绘制，为本项目占位素材，按仓库 GPL v3 分发。参考视频中的角色未作为程序素材使用。

## 自动验证及已知边界

本机 Release 构建无警告、无错误；14 项协议测试通过，包含新增的账号失效事件检查。WPF 验证模式不显示桌面窗口、不创建托盘、不使用个人设置；生成真实界面渲染图和 JSON 检查报告：

```powershell
dotnet tests/CutePet.Tests/bin/Release/net8.0/CutePet.Tests.dll
dotnet src/CutePet.Desktop/bin/Release/net8.0-windows/CutePet.dll --verify artifacts/desktop-verification
```

17 项检查通过，包括缺失/损坏设置恢复、比例校验、空额度、两个额度窗口、低额度与耗尽、倒计时归零、旧数据标记、账号变化清空、大小与置顶保存，以及命名同步对象的重复实例检测与通知。已检查 100%、150%、200% 分辨率的 WPF 离屏渲染；这不等同于真实显示器 DPI 切换测试。

真实账号模式额外通过一次官方查询，把返回快照送入桌宠显示模型并生成预览，合计 18 项检查。只在维护者本机运行，不向 CI 添加账号或凭据：

```powershell
dotnet src/CutePet.Desktop/bin/Release/net8.0-windows/CutePet.dll --verify-live artifacts/desktop-live
```

真实模式输出 `live-snapshot.json` 为项目模型允许的额度字段，仍应保留在本机，不把个人额度历史提交仓库。自动模式退出码 0 为通过，1 为失败；报告记录原因。GitHub Actions 运行不带账号的构建、协议测试与 WPF 验证。

| 人工验收项 | 状态 / 预期 |
|---|---|
| 鼠标拖动、点击、右键、缩放 | 待验收：不误触刷新，操作后保存位置与大小 |
| 托盘显示、隐藏、恢复、退出 | 待验收：隐藏后可恢复，退出后无自有辅助进程 |

| 重启恢复偏好 | 待验收：窗口位置、大小、置顶正确 |
| 100% / 150% / 200% 实际显示器及多屏拔插 | 待验收：文字完整，窗口不留在屏幕外 |

人工验收前称为开发原型，不标为完整桌宠发布版。

## 打包

在 Windows x64 开发机上构建框架依赖的便携目录：

```powershell
dotnet publish src/CutePet.Desktop -c Release --self-contained false -o artifacts/CutePet-Desktop
```

随目录附上仓库 `LICENSE`、本说明与对应源码提交链接，再压缩整个目录。当前没有自动 Release、开机启动和安装器。正式版携带运行环境的计划见 [开发文档](development.md)。
