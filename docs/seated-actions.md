# 坐姿互动（0.13.0）

日期：2026-10-02。天依坐稳以后使用独立坐姿图片眨眼、微笑和小幅抬手回应，动作结束保持原来的坐姿和王座。

## 体验

退出旧桌宠，完整解压新版并启动 CutePet.exe。选择内置「洛天依（同人）」，右键或托盘 →「召唤王座 / 坐下休息」。坐稳后每 4 秒尝试一次坐姿眨眼；不悬停角色时，每隔随机 8–16 秒尝试微笑。点击随机播放坐姿挥手或微笑，结束回到坐姿，不会因普通点击起身。

需要起身时，右键或托盘选择「起身并收起王座」。坐下 / 召唤尚未完成时，点击仍沿用按当前姿势反向起身，再播放站姿回应的行为。起身期间连续点击仍只保留最近一次站姿回应。

自动坐下后的坐姿点击会重新计休息时间，保留自动起身；有限坐姿动作播放期间不累计自动休息的坐稳时间。手动坐下仍持续到手动起身、拖动、隐藏、换角色或新鲜低额度等中断。菜单打开、按住鼠标和拖动时不触发自动微笑 / 眨眼；鼠标悬停角色时不触发自动微笑。详情与乘云的原有行为保留。

管理 / 导入角色 → 选择天依 → 动作下拉框可单独预览「坐姿眨眼 / 坐姿挥手 / 坐姿微笑」。新版共 13 种内置天依动作。此前导入的自定义天依不会自动更新，切回内置天依或导入本版变体即可体验。

## 角色包

保持 formatVersion: 1，新增三个可选有限动作：sit-blink、sit-greeting、sit-happy，均需要 sit 基础动作。不提供新动作的旧包继续使用原来的坐姿和起身回应。只提供一种坐姿点击回应时，点击始终播放该动作；不把站姿眨眼用于坐姿。

内置 sit-blink 为闭眼 160 毫秒、原坐姿 140 毫秒；sit-greeting 为原坐姿 120 毫秒、小幅抬手 600 毫秒、原坐姿 180 毫秒；sit-happy 为微笑 650 毫秒、原坐姿 150 毫秒。坐姿反应不使用整个人物或王座的倾斜 / 浮动变换。

三张新增透明 PNG 为 1024×1535，原素材保留。内置天依现有 20 张人物图与 1 张云层，总解码像素 33,010,338，继续低于原来的 33,554,432 上限。完整提示词见天依包 SEATED-PROMPTS.md / SOURCE.md；来源和原角色权利说明沿用此前同人素材记录。

## 验证

348 项 WPF / 功能检查及 14 项额度协议测试通过。新增检查覆盖坐姿动作完成回到原图、连续点击不积压队列、只提供一个坐姿回应的角色包、低额度 / 重置 / 隐藏清理、手动起身、自动休息保留、菜单阻止自动微笑、管理预览、缺少 sit 的非法包及循环动作拒绝。

seated-motion.gif 从实际 WPF 主窗口录制，模拟额度为 5h 72% / 周 48%。预览共 10 帧、5 秒循环，依次展示坐稳、眨眼、微笑、抬手回应，使用与桌宠相同的帧时长。验证使用隔离设置和屏幕外窗口，不操作用户桌宠或开机启动项。

这是小动作的第一版，仍为逐帧图片，抬手目前只有一张变化姿态；实际桌面观感与连续动画流畅度需要试用判断。
