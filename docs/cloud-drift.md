# 乘云飘动（0.11.0）

日期：2026-10-02。这是短距离乘云的第一版。沿用天依的现有人物图片，增加透明小云图层；属于本项目的同人设计。

## 体验方式

退出旧桌宠，完整解压新版，启动 CutePet.exe，选择内置「洛天依（同人）」。右键或托盘 → **召唤小云 / 飘一会儿**，然后将鼠标移开。约 0.7 秒施法、0.5 秒云形成并抬起人物，随后约 8 秒横向移动、0.5 秒云散去。人物保持正面朝向，不强行左右翻转衣服和饰品。

**自动乘云飘动** 默认开启，开关重启保留；在可以移动的待机时间累计约 18 秒后尝试出发。关闭后仍可手动召唤。最多移动 96 个逻辑像素，随角色大小和所在屏幕 DPI 缩放；下次尝试相反方向。靠近当前屏幕的工作区边缘会选择有空间的一侧，空间不足时缩短行程。人物和额度条作为同一个窗口移动，额度一直保留。

鼠标进入窗口附近约 28 个物理像素、停留在角色或额度条、查看详情、打开菜单或角色管理窗口时，冻结当前动作和行程；移开并关闭这些界面后继续。固定显示详情会持续暂停，需要收起或切换显示模式后移动。

点击会结束乘云并回应；拖动角色或额度条立即接管位置。锁定位置会结束并禁止移动。坐下休息、换角色、调整大小或额度条方向、移回右下角、隐藏和新鲜低额度也会结束乘云。云不会与王座同时显示。乘云时停止普通浮动、眨眼和随机张望，结束后恢复。额度同步不受移动影响。

王座自动休息和乘云共用同一个角色时钟：乘云期间暂缓休息触发，坐下期间不启动乘云。手动坐下持续至交互中断。小猫及未提供云层的旧角色包保留原行为。

## 角色包接入

保持 formatVersion: 1，新增可选字段：

```json
"cloud": {
  "image": "cloud.png",
  "displayWidth": 140,
  "displayHeight": 32
}
```

图片是独立云层，应提供透明背景；宽 40–190、高 12–40 个逻辑像素。云层允许自己的画布大小，但仍计入每包 25,165,824 解码像素、单张 8 MiB / 2048 像素边长限制，路径保护和其他图片一致。程序在角色脚下居中显示，不包含脚本。

可在 actions 中添加有限的 **summon-cloud** 动作。它必须有 cloud 配套，动作帧仍与人物其他帧保持同一画布；云在配置的施法动作结束后才出现。未提供施法动作时直接形成云。完整流程的运动、淡入淡出和轻微云浮动由程序处理。管理窗口只预览图层与动作，不移动管理窗口。带 summon-cloud 的包需要 0.11.0 或更新版；旧角色包继续可用。内置包导出包含云层与来源说明。

## 实现与验证边界

CloudFlight 计算阶段、插值和有边界的目标位置；CloudMotionController 协调角色动作、界面中断与保存；NativePlacement 读取窗口实际物理大小及当前显示器工作区，通过无激活的位置更新移动窗口。每次行程结束保存位置，暂停不积累时间，也不每帧写设置。设置的 AutoCloud 默认 true。

自动验证包含行程时序、淡入 / 抬升 / 落下、负坐标显示器与缩放边界、光标 / 菜单 / 详情暂停、位置锁定、王座互斥、拖动和布局变更、低额度、点击回应、隐藏 / 换角色、设置恢复、独立云画布导入导出、路径与像素限额及真实 WPF 时钟。验证使用隔离设置、模拟额度和屏幕外窗口，不移动用户桌面。实际跨 DPI 显示器、屏幕边缘、鼠标接管和长时间观感仍需桌面试用。

本版 275 项 WPF / 功能检查和 14 项额度协议测试通过。预览截图中的 5h 72% / 周 48% 是模拟数据。

目前只沿当前显示器工作区横向短距离飘动；尚未实现整个桌面随机巡游、跨显示器移动或边缘探头。沿用逐帧人物素材，小云由内置 image_gen.imagegen 生成，完整提示词与素材来源随包保留。
