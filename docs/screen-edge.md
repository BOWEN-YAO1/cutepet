# 屏幕边缘互动（0.18.0）

选择内置“洛天依（同人）”，解锁位置，将人物拖至当前屏幕可用区域的上、下、左、右边缘，释放时人物窗口距离边缘不超过 24 个逻辑像素，就会贴边探头。额度窗口的位置不变。允许部分人物窗口被拖出屏幕，释放后完整窗口会回到可用区域。

左右贴边时手扶边缘；上侧从屏幕外俯身探头，仅露头、短发和两只轻搭上沿的小手；下侧双手托腮、手肘落在任务栏上沿。约 320 毫秒滑入贴边位置。点击或悬停人物 400 毫秒后，会轻轻探头 / 抬头、微笑，再恢复基础姿势；无人交互时每隔 8–16 秒尝试一次。单次回应约 1 秒，重复点击不积压动作。打开菜单或按住鼠标会暂停动作时钟。

右键人物、额度面板或托盘，可以开关“屏幕边缘互动”，默认打开，重启保留开关。小猫和未提供贴边姿势的自定义角色保持普通拖动，开关在这些角色下不可操作。贴边姿势不跨重启保存；重启保留位置、恢复正常姿势，再次拖至边缘才触发。

## 退出贴边

- 开始拖动人物即恢复站姿，拖离后保持正常；释放在另一侧可以重新贴边。
- “召回到额度旁”退出贴边，额度保持原位。
- 手动乘云或坐下会先退出贴边；贴边期间自动乘云、自动坐下和站姿浮动暂停。
- 关闭边缘互动、换角色、隐藏或退出、重置位置、人物大小变化、新鲜低额度会退出贴边。
- 锁定位置可保持已有贴边姿势与点击回应，禁止新的拖动；明确召回依然可用。单独调整额度大小或移动额度不会解除贴边。

## 范围与实现

本版支持四个方向的屏幕**可用区域**边缘，遵守任务栏占用区域。尚不支持前台应用窗口边框、拖动其他窗口带着人物移动。贴边只在人物手动拖动释放时触发，乘云到达边缘不会自动贴上。

沿用人物 / 额度两个独立窗口，不新增全屏透明窗口。人物窗口保持在屏幕内，使用角色图片局部裁切、水平镜像和轻微位移呈现从边缘探头；不会把角色图片旋转成横躺姿势，也不会裁切、镜像或移动额度。位移使用缓入缓出，表情仍为少量姿势帧切换，后续可追加中间表情帧。

布局计算使用真实屏幕像素，吸附距离按显示缩放换算。多屏使用拖动结束时人物窗口所在的显示器；不会自动跨屏贴边。多屏不同 DPI 的实际拖动、任务栏位于侧边、显示器热插拔仍需要桌面试用确认。

## 角色包接入

包格式继续为 `formatVersion: 1`，全部旧动作兼容。支持以下六个可选动作：

| 动作 | loop | 含义 |
|---|---|---|
| edge-idle | true | 左右贴边基础姿势；任一方向基础姿势存在即可启用开关 |
| edge-peek | false | 有限探头回应，需要 edge-idle；结束回到左右贴边基础姿势 |
| edge-top-idle | true | 从上方探头的基础姿势，可独立提供 |
| edge-top-peek | false | 上沿回应，需要 edge-top-idle；结束回到上沿姿势 |
| edge-bottom-idle | true | 下沿托腮基础姿势，可独立提供 |
| edge-bottom-peek | false | 下沿回应，需要 edge-bottom-idle；结束回到托腮姿势 |

所有人物 PNG 仍使用同一画布大小。制作**左侧**边缘姿势，人物向右探出；右侧由程序镜像。画面不应绘制实体墙壁或边框。`edgeAnchorX` 是左侧虚拟边缘在画布宽度中的比例，范围 0–0.5，默认 0；天依使用 0.06，让手扶的位置对齐边缘。新增 `edgeTopAnchorY`（默认 0，范围 0–0.5）与 `edgeBottomAnchorY`（默认 1，范围 0.5–1），分别标记手 / 手肘接触线在画布高度中的比例。天依使用 0.12 / 0.9。上下姿势需要单独绘制，不翻转左右图片。管理窗口可分别预览这些动作，预览仅展示图片变化，实际贴边位置须拖动人物体验。

0.16.0 的两张左右动作图保留；0.17.0 新增 `edge-top-v1.png`、`edge-top-smile-v1.png`、`edge-bottom-v1.png`、`edge-bottom-smile-v1.png`，均为 1024×1535 透明图。0.18.0 用 `edge-top-v2.png` / `edge-top-smile-v2.png` 替换上侧动作引用，旧上侧图保留在源码。当前引用 26 张人物图及 1 张云层，总解码像素 42,441,378。角色包上限调整为 44,040,192 像素（约 168 MiB 未压缩 BGRA），继续限制每张 8 MiB / 2048 像素边长、120 帧引用和 ZIP / 解压后 64 MiB。完整提示词在天依包 `EDGE-PROMPTS.md`、`VERTICAL-EDGE-PROMPTS.md`、`TOP-EDGE-PROMPTS.md` 与可导出的 `SOURCE.md`。使用内置 image_gen 工具，生成图原样复制进包，角色权利说明沿用此前记录。

## 任务栏与边界调整

任务栏在底部正常显示时，下沿对齐系统桌面可用区域的底边，也就是任务栏上沿，人物窗口不进入任务栏区域。可用区域延伸到屏幕底部、未保留任务栏高度时（例如自动隐藏任务栏），统一额外留出 12 个逻辑像素的底部空间，方便鼠标唤出。程序不修改任务栏设置，也不自行猜测其展开高度。

任务栏显示状态、可用区域或 DPI 导致实际像素大小变化后，仍保持原来的贴边方向，重新对齐新边缘，正在播放的表情不中断。新的区域放不下人物时，退出贴边并约束普通窗口位置。用户主动改变人物大小仍按原规则退出贴边。

接近角落时，选择距离最近且当前角色支持的方向；相同距离按左、右、上、下的固定顺序决定，避免反复切换。旧版角色包只有左右动作时，只触发左右；上下姿势可单独提供，缺少对应回应动作时保持基础姿势。乘云边界仍沿用原来的系统工作区，不受贴边专用底部间距影响。

上侧回应只切换专用眨眼微笑帧，不拉伸或移动整个头部；下侧使用专用表情帧与围绕手肘接触线最多 4% 的伸展模拟抬头。两侧的接触线保持固定。这不是骨骼动画或逐帧视频，后续可以继续补绘头部中间姿势。

## 验证

构建后运行桌宠 `--verify`，验证使用隔离设置和不可见窗口，不连接账号或修改用户开机启动项。新增检查覆盖负坐标显示器、100% / 150% / 200% 缩放、吸附阈值、越界释放、表情与移动同步暂停、拖离、召回、锁定、开关保存、角色切换、低额度、乘云 / 王座衔接及角色包导入导出和非法配置拒绝。

输出 `screen-edge.gif` / `vertical-edge.gif` 分别展示实际 WPF 左右 / 上下贴边姿势与固定额度卡片，人物为便于观察放大显示，边框是屏幕示意，非用户桌面录屏。自动检查不能代替真实鼠标拖动与多显示器试用。
