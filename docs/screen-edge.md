# 屏幕边缘互动（0.16.0）

选择内置“洛天依（同人）”，解锁位置，将人物拖至当前屏幕可用区域的左侧或右侧，释放时人物窗口距离边缘不超过 24 个逻辑像素，就会贴边探头。额度窗口的位置不变。允许部分人物窗口被拖出屏幕，释放后完整窗口会回到可用区域。

贴边时手扶边缘、身体藏在外侧，约 320 毫秒滑入贴边位置。点击或悬停人物 400 毫秒后，会轻轻探出、微笑，再收回；无人交互时每隔 8–16 秒尝试一次。单次回应约 1 秒，重复点击不积压动作。打开菜单或按住鼠标会暂停动作时钟。

右键人物、额度面板或托盘，可以开关“屏幕边缘互动”，默认打开，重启保留开关。小猫和未提供贴边姿势的自定义角色保持普通拖动，开关在这些角色下不可操作。贴边姿势不跨重启保存；重启保留位置、恢复正常姿势，再次拖至边缘才触发。

## 退出贴边

- 开始拖动人物即恢复站姿，拖离后保持正常；释放在另一侧可以重新贴边。
- “召回到额度旁”退出贴边，额度保持原位。
- 手动乘云或坐下会先退出贴边；贴边期间自动乘云、自动坐下和站姿浮动暂停。
- 关闭边缘互动、换角色、隐藏或退出、重置位置、人物大小变化、新鲜低额度、显示器可用范围或人物实际像素尺寸变化会退出贴边。
- 锁定位置可保持已有贴边姿势与点击回应，禁止新的拖动；明确召回依然可用。单独调整额度大小或移动额度不会解除贴边。

## 范围与实现

本版支持左右两侧的屏幕**可用区域**边缘，遵守任务栏占用区域。尚不支持屏幕上下边缘、前台应用窗口边框、拖动其他窗口带着人物移动。贴边只在人物手动拖动释放时触发，乘云到达边缘不会自动贴上。

沿用人物 / 额度两个独立窗口，不新增全屏透明窗口。人物窗口保持在屏幕内，使用角色图片局部裁切、水平镜像和轻微位移呈现从边缘探头；不会把角色图片旋转成横躺姿势，也不会裁切、镜像或移动额度。位移使用缓入缓出，表情仍为少量姿势帧切换，后续可追加中间表情帧。

布局计算使用真实屏幕像素，吸附距离按显示缩放换算。多屏使用拖动结束时人物窗口所在的显示器；不会自动跨屏贴边。多屏不同 DPI 的实际拖动、任务栏位于侧边、显示器热插拔仍需要桌面试用确认。

## 角色包接入

包格式继续为 `formatVersion: 1`，全部旧动作兼容。新增两个可选动作：

| 动作 | loop | 含义 |
|---|---|---|
| edge-idle | true | 贴边基础姿势；存在此动作才启用边缘互动 |
| edge-peek | false | 有限探头回应，需要 edge-idle；结束回到贴边基础姿势 |

所有人物 PNG 仍使用同一画布大小。制作**左侧**边缘姿势，人物向右探出；右侧由程序镜像。画面不应绘制实体墙壁或边框。`edgeAnchorX` 是左侧虚拟边缘在画布宽度中的比例，范围 0–0.5，默认 0；天依使用 0.06，让手扶的位置对齐边缘。管理窗口可分别预览这两个动作，预览仅展示图片变化，实际贴边位置须拖动人物体验。

本次新增 `edge-v1.png`、`edge-smile-v1.png`，均为 1024×1535 透明图；原素材保留。天依现有 22 张人物图及 1 张云层，总解码像素 36,154,018。角色包上限调整为 36,700,160 像素（约 140 MiB 未压缩 BGRA），继续限制每张 8 MiB / 2048 像素边长、120 帧引用和 ZIP / 解压后 64 MiB。完整提示词在天依包 `EDGE-PROMPTS.md` 与可导出的 `SOURCE.md`。使用内置 image_gen 工具，生成图原样复制进包，角色权利说明沿用此前记录。

## 验证

构建后运行桌宠 `--verify`，验证使用隔离设置和不可见窗口，不连接账号或修改用户开机启动项。新增检查覆盖负坐标显示器、100% / 150% / 200% 缩放、吸附阈值、越界释放、表情与移动同步暂停、拖离、召回、锁定、开关保存、角色切换、低额度、乘云 / 王座衔接及角色包导入导出和非法配置拒绝。

输出 `screen-edge.gif` 展示实际 WPF 左右贴边姿势与固定额度卡片，人物为便于观察放大显示，边框是屏幕示意，非用户桌面录屏。自动检查不能代替真实鼠标拖动与多显示器试用。
