# 屏幕边缘互动（0.21.0）

选择内置“洛天依（同人）”，解锁位置，将人物拖至当前屏幕可用区域的上、下、左、右边缘，释放时人物窗口距离边缘不超过 24 个逻辑像素，就会进入该方向的边缘动作。额度窗口的位置不变。允许部分人物窗口被拖出屏幕，释放后完整窗口会回到可用区域。

左右贴边时手扶边缘；上侧坐在屏幕上沿悬挂的青玉云纹秋千上轻轻摆动，坐板带细金边、玉环与青色流苏，两根悬绳各加两枚莲花玉珠挂饰、金结、飘带和短流苏，绳上点缀小玉珠；下侧双手托腮、手肘落在任务栏上沿。约 320 毫秒滑入贴边位置。点击或悬停人物 400 毫秒后，左右 / 下侧会探头或抬头微笑，上侧秋千短暂加大摆幅，再恢复基础幅度；无人交互时每隔 8–16 秒尝试一次。单次回应约 1 秒，重复点击不积压动作。打开菜单或按住鼠标会暂停动作时钟。

右键人物、额度面板或托盘，可以开关“屏幕边缘互动”，默认打开，重启保留开关。小猫和未提供贴边姿势的自定义角色保持普通拖动，开关在这些角色下不可操作。贴边姿势不跨重启保存；重启保留位置、恢复正常姿势，再次拖至边缘才触发。

## 退出贴边

- 开始拖动人物即恢复站姿，拖离后保持正常；释放在另一侧可以重新贴边。
- “召回到额度旁”退出贴边，额度保持原位。
- 手动乘云或坐下会先退出贴边；贴边期间自动乘云、自动坐下和站姿浮动暂停。
- 关闭边缘互动、换角色、隐藏或退出、重置位置、人物大小变化、新鲜低额度会退出贴边。
- 锁定位置可保持已有贴边姿势与点击回应，禁止新的拖动；明确召回依然可用。单独调整额度大小或移动额度不会解除贴边。

## 范围与实现

本版支持四个方向的屏幕**可用区域**边缘，遵守任务栏占用区域。尚不支持前台应用窗口边框、拖动其他窗口带着人物移动。贴边只在人物手动拖动释放时触发，乘云到达边缘不会自动贴上。

沿用人物 / 额度两个独立窗口，不新增全屏透明窗口。人物窗口保持在屏幕内，使用角色图片局部裁切、水平镜像和轻微位移呈现从边缘探头；不会把角色图片旋转成横躺姿势，也不会裁切、镜像或移动额度。位移使用缓入缓出，表情仍为少量姿势帧切换，后续可追加中间表情帧。

布局计算使用真实屏幕像素，吸附距离按显示缩放换算。多屏使用拖动结束时人物窗口所在的显示器；不会自动跨屏贴边。多屏不同 DPI 的实际拖动、任务栏位于侧边、显示器热插拔仍需要桌面试用确认。

## 角色包接入

包格式继续为 `formatVersion: 1`，全部旧动作兼容。支持以下六个可选动作：

| 动作 | loop | 含义 |
|---|---|---|
| edge-idle | true | 左右贴边基础姿势；任一方向基础姿势存在即可启用开关 |
| edge-peek | false | 有限探头回应，需要 edge-idle；结束回到左右贴边基础姿势 |
| edge-top-idle | true | 上側基础姿势，可独立提供；可配置秋千 |
| edge-top-peek | false | 上沿回应，需要 edge-top-idle；结束回到上沿姿势 |
| edge-bottom-idle | true | 下沿托腮基础姿势，可独立提供 |
| edge-bottom-peek | false | 下沿回应，需要 edge-bottom-idle；结束回到托腮姿势 |

所有人物 PNG 仍使用同一画布大小。制作**左侧**边缘姿势，人物向右探出；右侧由程序镜像。画面不应绘制实体墙壁或边框。`edgeAnchorX` 是左侧虚拟边缘在画布宽度中的比例，范围 0–0.5，默认 0；天依使用 0.06，让手扶的位置对齐边缘。新增 `edgeTopAnchorY`（默认 0，范围 0–0.5）与 `edgeBottomAnchorY`（默认 1，范围 0.5–1），分别标记手 / 手肘接触线在画布高度中的比例。天依使用 0 / 0.9，上侧 0 表示秋千的虚拟悬挂中心在画布顶部。上下姿势需要单独绘制，不翻转左右图片。管理窗口可分别预览这些动作，预览仅展示图片变化，实际贴边位置须拖动人物体验。

0.16.0 的两张左右动作图保留；0.17.0 新增 `edge-top-v1.png`、`edge-top-smile-v1.png`、`edge-bottom-v1.png`、`edge-bottom-smile-v1.png`，均为 1024×1535 透明图。0.18.0 用 `edge-top-v2.png` / `edge-top-smile-v2.png` 替换上侧动作引用，旧上侧图保留在源码。0.19.0 上侧使用 `swing-v1.png` 坐姿，回应沿用同一张图并短暂增加摆幅；未接入不稳定的微笑帧。0.20.0 上侧改用 `swing-jade-v2.png`，月白青玉云纹坐板加细金边、玉环、短流苏，绳索颜色改为青玉色。0.21.0 加入独立 `rope-ornament-v1.png`；坐姿仍用青玉 v2，进一步重绘尝试被图像工具审核拦截，未接入。当前引用 25 张人物图、1 张云层和 1 张挂饰图，总解码像素 42,441,378。角色包上限调整为 44,040,192 像素（约 168 MiB 未压缩 BGRA），继续限制每张 8 MiB / 2048 像素边长、120 帧引用和 ZIP / 解压后 64 MiB。完整提示词在天依包 `EDGE-PROMPTS.md`、`VERTICAL-EDGE-PROMPTS.md`、`TOP-EDGE-PROMPTS.md`、`SWING-PROMPTS.md`、`JADE-SWING-PROMPTS.md`、`ORNAMENT-PROMPTS.md` 与可导出的 `SOURCE.md`。使用内置 image_gen 工具，生成图原样复制进包，角色权利说明沿用此前记录。

## 任务栏与边界调整

任务栏在底部正常显示时，下沿对齐系统桌面可用区域的底边，也就是任务栏上沿，人物窗口不进入任务栏区域。可用区域延伸到屏幕底部、未保留任务栏高度时（例如自动隐藏任务栏），统一额外留出 12 个逻辑像素的底部空间，方便鼠标唤出。程序不修改任务栏设置，也不自行猜测其展开高度。

任务栏显示状态、可用区域或 DPI 导致实际像素大小变化后，仍保持原来的贴边方向，重新对齐新边缘，正在播放的表情不中断。新的区域放不下人物时，退出贴边并约束普通窗口位置。用户主动改变人物大小仍按原规则退出贴边。

接近角落时，选择距离最近且当前角色支持的方向；相同距离按左、右、上、下的固定顺序决定，避免反复切换。旧版角色包只有左右动作时，只触发左右；上下姿势可单独提供，缺少对应回应动作时保持基础姿势。乘云边界仍沿用原来的系统工作区，不受贴边专用底部间距影响。

上侧使用整张坐姿绕悬挂中心左右摆动，约 3.2 秒一个周期，正常幅度 ±3°，回应中缓慢增加到最多 ±4°；不拉伸人物。两根绳子的上端固定在屏幕可用区域上沿，下端实时跟随坐板两端；绳子是独立 WPF 图层，坐姿素材不绘制绳子。旧角色包未配置秋千时保留原有上侧姿势。下侧使用专用表情帧与围绕手肘接触线最多 4% 的伸展模拟抬头。下侧接触线保持固定，上侧固定绳索顶端。这不是骨骼动画或逐帧视频，后续可以继续补绘头部中间姿势。

## 验证

构建后运行桌宠 `--verify`，验证使用隔离设置和不可见窗口，不连接账号或修改用户开机启动项。新增检查覆盖负坐标显示器、100% / 150% / 200% 缩放、吸附阈值、越界释放、表情与移动同步暂停、拖离、召回、锁定、开关保存、角色切换、低额度、乘云 / 王座衔接及角色包导入导出和非法配置拒绝。

输出 `top-swing.gif` 为实际 WPF 秋千两周期预览；`screen-edge.gif` / `vertical-edge.gif` 分别展示实际 WPF 左右 / 上下贴边姿势与固定额度卡片，人物为便于观察放大显示，边框是屏幕示意，非用户桌面录屏。自动检查不能代替真实鼠标拖动与多显示器试用。

## 自定义秋千配置

角色包保持 `formatVersion: 1`。提供 `edge-top-idle` 后，可选加上：

```json
"edgeTopAnchorY": 0,
"topSwing": {
  "seatAnchorY": 0.69,
  "seatHalfWidth": 0.36,
  "ropeColor": "#77B4A8",
  "ornament": {
    "image": "rope-ornament-v1.png",
    "displayWidth": 18,
    "displayHeight": 27
  }
}
```

`seatAnchorY` 是坐板连接线在人物画布高度中的比例，必须大于 `edgeTopAnchorY + 0.1` 且不超过 0.95。`seatHalfWidth` 是画布中心到每个坐板连接点的宽度比例，范围 0.1–0.5。绳索颜色只接受 `#RRGGBB`。省略 `topSwing` 不启用摆动或绳子。缺少 `edge-top-peek` 时仍自动轻摆，点击不额外加大摆幅。管理窗口预览仅播放素材帧，不展示绳索与摇摆，请拖至屏幕上侧体验实际动作。

这版是小幅二维摇摆，衣服、头发和腿部尚未独立运动。打开菜单或按住鼠标暂停，锁定位置保留轻摆。拖离、召回、关闭开关或换角色会清除绳索和旋转；重启仍需重新拖到边缘触发。


## 可选悬绳挂饰

`topSwing.ornament` 是独立的角色包图层，可省略。`image` 使用与动作图片相同的安全 PNG 路径规则；画布大小可与人物不同，单图 8 MiB / 2048 边长限制及角色包总像素限制继续适用。`displayWidth` 范围 6–30，`displayHeight` 范围 8–44，默认 18×27 个逻辑像素，并随人物绘制高度和窗口缩放一起变化。用于挂饰的画布应将悬挂点置于顶部中央，四周透明。

每根绳索在长度 13% 与 58% 处各放一枚挂饰，43% 与 88% 处点缀小玉珠。挂饰沿绳索实时跟随，带最多 ±4° 的轻微滞后摆动；打开菜单或按住鼠标暂停。装饰位于人物图层后方，不拦截点击和拖动。退出贴边或换角色会清除图片引用；无挂饰配置的旧角色保持普通悬绳。

角色包导入 / 导出包括挂饰配置和当前引用图片；同一图片被多个图层引用时只解码一次。挂饰像素计入原有 44,040,192 上限，不增加上限。自动检查覆盖实际导入导出、独立画布、路径和大小校验、缺失素材、像素预算、绳索跟随、暂停、缩放及旧角色清理。挂饰为静态透明图片的整体摆动，尚无流苏逐根或飘带骨骼动画。
