# 侧边播放稳定性（0.45.0）

0.44.0的144级探出仍被反馈为一顿一顿。本版沿用144张探出、16张点头、16张轻摇，不将实时混合输出计为新的源绘图。修改重点为播放衔接、预览一致性和反复分配。

## 发现与修改

- 角色管理页原先每20毫秒直接设置 `animation.Image`，跳过桌宠使用的帧间过渡。现在两处共用 `CharacterFrameRenderer`，由屏幕绘制事件驱动，按经过时间推进；同一个绘制时间只处理一次。隐藏或销毁预览时退订事件并释放像素缓存。
- 新动作开始时重置实际播放时钟。切换角色或此前界面阻塞的耗时不能带入刚启动的预览，避免刚开始就跳过前一段。
- 侧边在既有配准帧间过渡后，增加35毫秒时间滤波。当前画面与上一输出先对齐到同一连续头部位置，再混合；位移在上方手掌前衰减至零，双手位置保持。时间不推进时保持相同输出，切换动作或时间倒退清空历史；接近终点时缩短滤波时间，恢复准确终点，防止切回待机时残留迟到的轮廓。
- 冻结源图片的像素最多缓存80 MiB，重复播放直接复用，超限按先入顺序淘汰。可变图片不加入缓存。切换角色或隐藏时清空缓存。整数双线性采样使用非负权重，四角权重总和固定，保持预乘颜色与透明度。
- 侧边窗口GIF改为每20毫秒采样（50 fps），同时缩为476×273，使内存和文件体积接近原来的680×390、25 fps预览。原始源图GIF仍独立提供，不展示实时稳定滤波。

## 隔离测量

`CutePet.exe --benchmark-animation <新JSON路径>`仅加载内置角色，在60次/秒的时间采样下，测量四种真实侧边动作的呈现耗时和当前线程分配；不打开桌面窗口、不读取或写入用户偏好、不消耗Codex额度。

同机926次呈现的一次前后测量：

| 指标 | 修改前 | 初次修改后（包含新增稳定过渡） |
|---|---:|---:|
| 平均呈现耗时 | 7.35 ms | 6.88 ms |
| 95%分位耗时 | 9.82 ms | 10.05 ms |
| 最长耗时 | 17.92 ms | 13.33 ms |
| 超过16.67 ms的次数 | 2 | 0 |
| 当前线程累计临时分配 | 569.34 MiB | 80.05 MiB |
| 源像素读取次数 | 未单独记录 | 176 |
| 保留源像素缓存 | 无整套缓存 | 74.25 MiB |

分配下降约86%，并不代表应用总内存下降相同比例。测量不包含系统合成、显卡负载、其他程序占用，也不能作为所有设备都能稳定60 fps的保证。新增滤波仍是图像过渡，复杂衣褶和遮挡存在原绘图差异；若反馈仍有局部变形，需针对源绘图结构进一步处理。

## 验证

隔离窗口验证覆盖：单一移动头部、固定双手、重复刷新暂停、准确终点、动作切换不残留历史、冻结源像素只读取一次、缓存超限淘汰及清空、角色管理页真实连续输出。原有左右边缘、菜单、快速点击、低额度、角色包导入导出和额度窗口位置继续验证。新包与旧包使用相同配置字段，旧包缺少平滑与配准字段时维持原有播放行为。

发布前 Release 构建通过，核心测试14项、隔离窗口与功能检查2,477项全部通过。隔离验证使用演示数据，不修改实际桌宠设置。
