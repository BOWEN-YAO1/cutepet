# 施法召唤王座与坐下休息（0.10.0）

2026-10-02。天依保留现有服装和鞋子，用五张新透明帧完成施法、王座显现、坐下过渡、坐姿和起身收回流程。歪头动作继续移除；小猫和旧角色包保留原行为。

## 使用方式

升级前退出旧桌宠，完整解压新版包并启动 CutePet.exe，选内置洛天依（同人）。右键或托盘 → **召唤王座 / 坐下休息**，即可马上体验。坐下后该入口变为 **起身并收起王座**。

| 阶段 | 表现与时长 |
|---|---|
| 施法并坐下 | 手旁魔法环 → 半透明王座 → 完整王座 → 下坐过渡 → 坐姿，共约 1.5 秒 |
| 坐着休息 | 保持坐姿，停止站姿眨眼、张望和上下浮动；额度同步继续 |
| 起身收回 | 起身过渡 → 站在王座前 → 王座变透明 → 收回魔法 → 普通站姿，共约 1 秒 |
| 点击坐着的天依 | 先起身收回，再随机挥手或开心回应；起身期间只保留最近一次点击的回应 |

自动休息默认开启：桌宠约 30 秒没有被点击、悬停或拖动后，尝试召唤王座；坐约 20 秒后起身。这里计时的是桌宠交互，不检测电脑全局空闲，也不代表 Codex 模型任务状态。右键 / 托盘 **自动坐下休息** 可以关闭，设置重启保留；关闭时已在坐姿的角色会起身。手动坐下持续到点击、手动起身或其他中断。

悬停角色、按住左键、拖动或打开菜单时暂停新的自动休息触发。拖动立即恢复普通基础姿势，隐藏和换角色清除家具与未完成回应。新鲜有效低额度仍优先显示疲惫表情并停止休息；点击回应结束回到当前额度状态。姿态不改变额度条方向、位置、大小和详情设置。

管理 / 导入角色中新增 **召唤王座、坐下休息、起身收起** 三种预览。预览独立于主桌宠和额度连接，选择坐姿可直接查看，选择召唤则会在有限流程结束后保持坐姿。

## 角色包扩展

继续采用 formatVersion: 1，新增三个可选动作：conjure（有限）、sit（循环基础姿态）、stand（有限）。conjure / stand 或自动休息必须配套 sit；仅提供 sit 的自定义角色也能手动坐下和恢复站姿，未提供起身素材时立即恢复。未提供 sit 的旧角色不触发休息，也不自动生成家具。

restAfterMs 默认 0，表示没有自动休息，启用范围 5000–300000 毫秒；restDurationMs 默认 20000，范围 1000–300000。内置天依配置为 30000 / 20000，用户 AutoRest 偏好可以暂停自动触发。坐姿期间不会使用站姿眨眼图，避免姿态跳回。

天依当前包含 14 张 1024×1535 PNG、9 种动作，总解码像素 22,005,760。每包解码上限调整为 25,165,824，其他单帧、压缩包、帧数及路径限制保留。图片解码冻结缓存；重复帧只引用缓存。完整素材与提示词在 Characters/Packs/tianyi/，THRONE-PROMPTS.md 的全部记录同样包含在 SOURCE.md 中并随角色包导出。

## 验证与边界

236 项隔离 WPF / 功能检查及 14 项额度协议测试通过。检查覆盖施法帧时序、持续坐姿、起身后回应、快速点击只保留最近回应、自动计时与开关保存、拖动 / 隐藏 / 换角色 / 低额度中断、旧包兼容、仅有坐姿的自定义包、导出再导入以及无坐姿的非法休息配置。真实 WPF 计时器验证召唤结束到坐姿，离屏渲染检查显示效果，不改个人设置或开机启动项。

人工体验：右键召唤，检查手、裙摆、扶手和脚底的衔接；坐着时点击、快速点击、拖动、隐藏恢复；关闭自动休息再手动坐下；在管理窗口逐个预览。素材仍是离散姿势，尚未实现骨骼补间或完整 Live2D 动画，观感需要实际桌面验收。

自由走动与屏幕 / 软件窗口边缘探头尚未实现，本版只完成王座休息流程。
