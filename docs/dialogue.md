# 角色台词（0.36.0）

内置天依有 60 句台词，小猫有 32 句，分别保存在各自角色包的 `character.json` 中。包含日间 / 早晨 / 夜间启动、点击、悬停、拖放、乘云、坐下、起身、左右 / 上侧 / 下侧互动、待机，以及额度低、同步恢复和连接中断。

设置 → 交流可选择 **安静 / 普通 / 活泼**，主动台词间隔分别为 180 / 90 / 45 秒，点击等直接回应最短间隔分别为 8 / 5 / 3 秒。默认普通并开启主动台词。关闭主动台词后，点击、首次启动问候和重要额度通知仍可显示；菜单、拖动、查看详情或角色预览时，主动台词计时暂停。设置重启保留。

每次从对应组随机选择，优先排除上次该组台词和上一句显示内容；仅提供一句的组仍可使用。气泡约 4–8 秒后自动收起，重要额度提醒优先于普通回应。隐藏、退出或切换角色立即清除气泡。气泡是临时、无焦点、鼠标穿透的 Popup，定位到人物窗口的上 / 下 / 左 / 右，边缘时向桌面内侧摆放，由 WPF 处理屏幕边界；乘云时跟随人物，不移动独立额度条。

额度低于 20% 时提醒一次；连续低额度刷新不重复提醒。连接中断提醒一次，取得新数据后提醒恢复；低额度恢复正常也提醒状态更新。这些台词不声称重置或具体消耗，真实数值和状态仍来自原来的官方额度读取器。台词是本地文本，不产生模型调用或额外费用。

## 自定义角色

`dialogue` 是可选字段，格式版本保持 1。旧 ZIP / PNG 未配置时使用中性通用台词。以下例子可与原有 `actions` 配置共存：

```json
"dialogue": {
  "click": ["在呢。", "你来啦。"],
  "cloud": ["搭朵云去兜风吧。"],
  "edge-top": ["秋千上的风景真好。"],
  "low": ["剩余额度有点少啦。"]
}
```

支持事件：`startup`、`morning`、`evening`、`click`、`hover`、`drag`、`cloud`、`rest`、`wake`、`edge-side`、`edge-top`、`edge-bottom`、`ambient`、`low`、`recovery`、`offline`。缺失的事件使用通用台词；某些事件仅在角色提供相应动作时触发。启动问候按本地时间选择：5:00–10:59 为早晨，19:00–4:59 为夜间，其余为日间。

每个事件 1–12 句，每句最多 80 字符，总计不超过 160 句，不允许空白、null、控制字符或未知事件名。整个配置仍限制为 64 KiB。台词不解释为代码或指令，导入 / 导出随 manifest 一起携带。旧版 CutePet 不使用此字段，台词功能需 0.36.0 或更新版本。

## 验证

`DialogueVerification` 覆盖随机防重复、冷却、三档计时、主动关闭、重要通知优先级、气泡寿命、隐藏和切换清理、非法包拒绝、导入导出完整性、真实按钮与文本绑定、额度状态转变、动作情境、负坐标屏幕四侧摆放及额度位置保持。原有隔离 `--verify` 流程同时验证全部旧功能。测试模式不会打开原生台词 Popup，也不接入真实账号或实际桌宠；真实鼠标、Popup 在多屏 DPI / 任务栏边缘的效果和长期体验仍需试用。

本版共通过 1,129 项窗口 / 功能检查、14 项额度协议测试，构建 0 警告 / 0 错误。角色页预览的图片和绳索层在尺寸完成更新后重新对齐，修正首次展开时偶发使用零宽布局的问题。
