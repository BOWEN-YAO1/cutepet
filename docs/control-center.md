# 应用主界面与图标（0.30.0）

日期：2026-10-03。把原来分散在右键菜单里的功能集中到一个普通 Windows 窗口，桌宠和小额度条继续独立运行。

0.29.1 清理界面文案：移除页头口号、重复状态、版本小字和底部常驻提示；活动与设置说明放到悬停提示，角色页只显示角色名称与操作，素材信息默认折叠。同步状态、重置时间、更新时间和实际错误继续显示；操作提示仅在有消息时出现。素材来源与许可文件保持完整。

## 打开和关闭

完整解压便携包，双击 CutePet.exe。手动启动会显示桌宠与主界面；再次运行程序会唤回同一个实例并打开主界面。

双击托盘图标可随时打开主界面。人物、额度、托盘右键菜单顶部有「打开主界面…」，额度悬停详情的标题栏也有「主界面」按钮。主界面可以最小化到任务栏，关闭窗口只关闭界面，不退出桌宠。真正退出请在设置页或托盘选择「退出 CutePet」。

主界面与人物互不作为所有者，隐藏桌宠仍可打开和操作主界面。概览中的「显示 / 隐藏桌宠」控制人物与独立额度窗口，不会隐藏主界面。启动项的 `--autostart` 参数使 Windows 登录启动保持主界面关闭；开机启动开关仍由用户手动开启。

## 四个页面

| 页面 | 功能 |
|---|---|
| 概览 | 官方额度窗口、剩余比例、重置倒计时、刷新状态和上次更新时间；当前角色预览、活动状态、显示 / 隐藏及召回 |
| 角色 | 内置与个人角色列表、切换、导入 PNG / ZIP、动作预览、导出和移除归档 |
| 活动 | 手动乘云、自由乘云开关、召回、王座休息 / 起身、自动休息、边缘互动及点击回应 |
| 设置 | 置顶、位置锁定、人物 / 额度独立大小、详情模式、额度快速摆放、开机启动、选择 Codex 程序、重置位置及退出 |

0.36.0 增加设置 → 交流：安静 / 普通 / 活泼三档，以及主动台词开关。角色的点击、乘云、王座和四边互动有各自台词，气泡自动收起；额度提醒只在状态变化时触发。完整规则与自定义格式见 [角色台词](dialogue.md)。

不支持的动作会禁用。例如小猫没有云层和坐姿，其乘云与王座按钮禁用；位置锁定、低额度、已经在巡游或尚未起身时也会更新按钮状态。菜单或外部角色切换会同步到主界面，不需要重新打开。

主界面与桌宠共享同一份额度状态，只展示已有会话的数据。连接中显示未知值「—」；刷新中禁用刷新按钮；失败时明确标记上次数据，清空状态时不推断比例；多个额度桶全部展示，并可滚动。刷新频率与官方读取逻辑继续沿用既有策略。

设置即时调用既有方法并保存，人物与额度大小互不联动。额度快速摆放是一次性放到人物对应方向，之后仍可独立拖动；不将它变成持续跟随人物的锚点。开机启动读取实际注册状态，写入失败时保留实际结果并在底部显示提示。选择 Codex 路径后仍需退出并重新启动程序生效。

角色页复用原角色库与播放器。首次打开时重载角色目录，会清理人物临时动作；页面可见时阻止桌面乘云，动作预览使用自己的时钟，切换页面或关闭窗口会暂停 / 释放。角色页只预览图片帧与云出现，不展示实际屏幕移动、悬绳和原生花藤。需要在活动页或拖到屏幕上沿体验。

默认主界面约 1000 × 740 DIP，允许缩放和最大化。较小工作区会在打开时缩小并约束到当前屏幕可用区域，页面内容支持滚动；正常最小值为 760 × 560 DIP，遇到更小的工作区可相应降低。保留 Windows 原生标题栏、任务栏入口、键盘焦点与导航状态。窗口尺寸和当前页暂不持久化。

## 颜色设置

设置页顶部提供「界面主色」和「字体颜色」，分别输入 R、G、B 三个 0～255 的整数。有效输入即时应用并自动保存，色块显示当前有效颜色；空值、字母、负数和越界值显示纠正提示，保留最后一次有效颜色。页面状态刷新不会覆盖尚未完成的输入。

默认主色为 RGB (232, 161, 182)，字体为 RGB (88, 58, 69)。背景、卡片、边框、导航、按钮、开关与进度条从主色派生，普通文字和额度数字使用字体颜色，次要文字由同一字体颜色略微淡化。点击「恢复默认粉色」可同时恢复两种颜色和输入框，包括已经是默认颜色但仍有无效草稿的情况。

颜色保存到既有 settings.json 的 ThemeColor / FontColor 字段，内部使用 #RRGGBB。旧设置缺少字段时使用粉色；无效或空颜色字段分别回退，不影响其他设置。关闭再打开、退出再启动均恢复保存的颜色。主界面全部页面共用动态颜色资源，已打开的页面同步更新。实际同步状态圆点保留其状态颜色。角色图片、独立桌面额度窗口、托盘图标和 Windows 原生标题栏不随主界面主题染色；Windows 原生下拉框等控件仍使用系统外观。

白色等浅色字体会让主按钮和 RGB 输入框使用深色底，确保仍能修改颜色或恢复默认。其他页面按用户选择显示。

## 图标

使用青玉色底、浅色小猫与云的项目原创矢量图标，统一用于 EXE、托盘、窗口标题栏和主界面品牌区。不是洛天依官方标识。矢量源位于 `src/CutePet.Desktop/Assets/Brand.xaml`，ICO 含 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 九档分辨率，另保存 512 PNG。全部由本项目 WPF 绘制工具渲染，无外部图标库或新增角色图片。

在 Windows 与 .NET 8 SDK 环境重建图标：

```powershell
dotnet run --project tools/CutePet.IconBuilder -- src/CutePet.Desktop/Assets/Brand.xaml src/CutePet.Desktop/Assets
```

图标随项目按 GPL v3 分发。程序集和 EXE 嵌入同一 ICO，托盘读取打包资源而不是运行时临时画字母。Windows 对旧快捷方式图标可能保留缓存；完整解压到新版目录，并通过新版 CutePet.exe 启动。

## 扩展入口

`Views/ControlCenter/` 按页面组织：

```text
ControlCenterWindow.*     窗口、导航、页面缓存和生命周期
CenterTheme.xaml          字体、按钮、开关与动态颜色样式
CenterColors.cs           RGB 解析、默认粉色与动态调色板
RgbColorEditor.cs         有效颜色与未完成输入的独立状态
RgbEditor.*               可复用 RGB 输入与色块预览
CenterViewModel.cs        既有额度 / 设置状态映射及共享操作命令
OverviewPage.*            额度与当前角色概览
CharactersPage.*          从旧管理窗口抽出的可复用角色页面
ActivityPage.*            角色能力和活动开关
SettingsPage.*            颜色、桌面布局、启动和连接设置
```

新增功能先加入对应页面；需要独立页面时，增加 UserControl，并在 ControlCenterWindow 的导航标签与 Navigate 工厂中登记。动作和设置更新继续调用 MainWindow 中的现有入口；设置变化通过 DesktopStateChanged 传播，额度变化通过 PetViewModel.PropertyChanged 传播。主界面只在可见时每秒刷新活动状态，不新建 QuotaSession、不复制账号状态、不增加另一份设置文件。

旧 CharacterManagerWindow 保留为 CharactersPage 的兼容外壳，自动检查继续使用它验证原角色功能；应用中的角色管理入口统一跳转主界面的角色页。
