# 活动节奏与动作衔接（0.37.0）

这版使用已有角色素材改善动作安排和位移衔接，不新增角色图集或改变角色包格式。默认行为立即生效，原有自动休息、自由乘云与边缘互动开关继续使用。

## 自动活动

乘云和休息交给同一个待机计划。两项都可用时，首次随机选择一项；一次活动之后优先安排另一项，避免连续乘云挤占休息或起身后立即再次坐下。只有一项可用时，该项仍正常执行。手动乘云 / 坐下也会更新最近活动记录。

每次安排时随机确定等待时间，活动期间不会重抽该计划：自动乘云等待 25–50 秒可活动的待机时间；自动休息等待角色配置 `restAfterMs` 的 85%–125%。坐下后自动停留为 `restDurationMs` 的 85%–130%。手动坐下仍由用户决定何时起身。

人物正在施法、回应、乘云、收云、坐着、起身或贴边时，不累积另一项大型活动。鼠标靠近人物、菜单、额度详情和角色预览期间暂停自动活动；悬停、点击、召回、拖动及活动完成后重新留出一段待机时间。开关改变时若原计划不再可用，按仍可用的活动重新安排，关闭两项后保持待机。隐藏或切换角色会清除临时计划，新鲜低额度仍立即停止移动。

## 小动作与过渡

- 站立张望间隔约 8–16 秒，坐姿回应约 10–22 秒，贴边自动回应约 12–26 秒。
- 坐姿的微笑、小挥手和眨眼，以及每个方向的自动贴边回应，按随机洗牌的一组动作挑选。每轮覆盖该角色提供的动作，尽量避免前后重复；只有一个动作的旧包也可正常使用。手动贴边点击保留逐个体验回应的方式。
- 普通眨眼在角色配置间隔的 80%–140% 之间变化，乘云巡航的眨眼间隔约 4.2–7 秒。
- 站立时的轻微起伏保持相位，启用和停用时用 320 毫秒逐渐调整幅度，减少坐下、乘云和回到待机时的位置突变。
- 乘云中点击人物立即停止路线并开始回应，云朵、抬升、人物 / 云层起伏、倾身、云层倾斜和呼吸幅度在 320 毫秒内一起收回。手动召唤王座也可接着这段短过渡开始，不等待额外施法队列。
- 收云期间不接受另一趟乘云，额度位置保持固定。拖动、锁定、隐藏、换角色、布局变化和低额度沿用立即清理的位置处理；长时间忙碌后不会补播多次动作。

人物仍使用有限姿势帧，本版不承诺连续骨骼动画。真实鼠标、多屏和长期节奏是否舒适，需要试用观察；后续如要更自然的肢体动作，再补素材过渡帧。

## 代码与验证

`BehaviorRhythm` 管理单一活动计划与随机动作袋，`IdleFloat` 保留轻浮相位，`CloudLanding` 保存当前位置对应的视觉姿态并有限收回。WPF 呈现仍由现有 `CharacterPresenter` / `CloudMotionController` / `EdgeMotionController` 管理。旧包通过提供的动作自动获得相应节奏，不新增必填 manifest 字段或用户设置。

`BehaviorVerification` 覆盖有界随机时长、计划稳定、两项活动不互相挤占、禁用和单动作包、随机覆盖与相邻不重复、起伏切换连续性、收云各通道、真实 WPF 自动休息到乘云、菜单 / 固定详情暂停、点击立即回应、王座衔接、锁定 / 换角色清理及额度保持固定。验证使用隐藏窗口和隔离设置，不接入真实账号或修改用户桌宠。`previews/animations/cloud-landing.gif` 来自真实 WPF 离屏渲染。

本版共通过 1,167 项窗口 / 功能检查、14 项额度协议测试，构建 0 警告 / 0 错误。离屏验证与时钟推进不替代真实鼠标、多屏和长期使用验收。
