# 角色包与自定义角色（0.8.0）

日期：2026-10-02。角色包包含图片、动作和来源说明；程序统一处理额度、点击、眨眼、拖动、大小与窗口位置。不需要为每个图片角色修改主程序。

## 直接使用

右键桌宠或托盘 → **管理 / 导入角色…**。

- **导入 PNG / 角色包…**：选择一张 PNG，或 ZIP 角色包。导入成功后立即使用；PNG 的文件名作为角色名。
- **使用此角色**：将列表中预览的角色用于桌宠，选择立即保存。
- **预览打招呼**：播放所选角色自己的 greeting 动作，没有该动作时按钮禁用。预览不消耗额度。
- **导出…**：保存可分享的 ZIP，包含配置、引用的图片和来源 / 许可说明。分享前确认自己的素材使用权限。
- **移除**：只移除自定义角色，保留本地归档。正在使用的角色移除后回到小猫。

小猫和洛天依始终内置可选，不能移除。单张图片不会自动生成挥手、眨眼等新姿态；它只有一个待机帧，默认仍有轻微浮动。缺少可选动作时回到待机。

导入的素材复制到 `%LOCALAPPDATA%\CutePet\Characters\<id>\`，不会上传，也不依赖原 ZIP / PNG 的路径。角色选择写入同目录上一层的 settings.json；旧版的 Character 选择自动迁移，缩放、额度条方向、锁定和其他偏好继续保留。修改已安装包后，重启或重新打开管理窗口刷新资源；暂不提供监视文件变化的实时热加载。

## 包结构

ZIP 根目录必须直接包含 character.json，不要把整个外层文件夹一并压进去。

```text
my-pet.cutepet.zip
├── character.json
├── idle.png
├── blink.png
├── greeting-1.png
├── greeting-2.png
├── low.png
├── SOURCE.md       可选，来源说明
└── LICENSE.txt     可选，素材许可证
```

动画图片也可以放在 `frames/` 等子目录。每个动作帧画布尺寸必须相同，推荐透明背景；人物大小、脚底和头部基准需要在素材中保持对齐，程序不会自动修正姿势偏移。

仓库的 `examples/character-pack/` 是可以直接压缩导入的完整小猫示例，采用 GPL v3 素材。修改 id 和 name 即可创建自己的包；替换 PNG 并补充真实来源说明后再分享。内置角色导出的 id 仍为 cat / tianyi，若要导入为自定义变体，先改成新的 id，避免替换内置角色。

## 最小静态配置

```json
{
  "formatVersion": 1,
  "id": "my-pet",
  "name": "我的桌宠",
  "author": "你的名字",
  "license": "你的素材许可或来源说明",
  "float": true,
  "actions": {
    "idle": {
      "loop": true,
      "frames": [{ "image": "idle.png", "durationMs": 1000 }]
    }
  }
}
```

## 多帧动作

每个动作的 frames 可包含多张 PNG，也可以重复引用同一张，durationMs 是该帧持续的毫秒数。例如将以下动作加到 actions 对象中：

```json
"greeting": {
  "loop": false,
  "frames": [
    { "image": "greeting-1.png", "durationMs": 120 },
    { "image": "greeting-2.png", "durationMs": 180 },
    { "image": "greeting-1.png", "durationMs": 120 },
    { "image": "idle.png", "durationMs": 120 }
  ]
}
```

| 动作 | 是否必需 | loop | 触发与结束 |
|---|---|---|---|
| idle | 必需 | true | 日常循环；可以单帧或多帧 |
| blink | 可选 | false | 正常待机时定时触发；打招呼或低额度期间不打断 |
| greeting | 可选 | false | 点击时播放；再次点击重新开始，不积压队列；结束回到当前额度状态 |
| low | 可选 | true | 新鲜有效额度低于 20% 时播放；旧数据或额度恢复后回到待机 |

待机及低额度动作必须循环，眨眼和打招呼必须有限播放。隐藏桌宠时停止帧计时器并清除临时动作，恢复后继续基础状态；切换角色清除旧动作。管理预览独立于桌宠，也没有账号连接。

## 配置字段

| 字段 | 默认值 / 范围 | 用途 |
|---|---|---|
| formatVersion | 1 | 包格式版本 |
| id | 必填 | 小写字母开头，后接小写字母、数字或短横线，最长 64 字符；同一角色库内唯一 |
| name | 必填，最长 60 字符 | 菜单和管理窗口名称 |
| author | 空，最长 200 字符 | 作者说明 |
| license | 空，最长 2000 字符 | 素材许可或权利说明，不会默认套用代码 GPL |
| displayWidth | 178，范围 40–210 | 角色在基础区域内的显示宽度 |
| displayHeight | 148，范围 40–148 | 显示高度，底部对齐；图片等比例适配 |
| float | true | 是否启用轻微上下浮动，false 可保持静态位置 |
| blinkIntervalMs | 4000，范围 1000–60000 | 自动眨眼间隔；未提供 blink 时无作用 |
| actions | 必须含 idle | 四种已支持动作及逐帧时间 |

角色大小菜单仍独立控制整体缩放，不需要修改包中的显示尺寸。动作帧最短 40 毫秒，播放器使用 40 毫秒 UI 计时器；实际调度受桌面负载影响，不保证逐帧的视频级时序。暂不支持 GIF、APNG、多层骨骼、声音、脚本、新触发类型或联网下载。

## 导入限制和失败处理

PNG 文件每张不超过 8 MiB，尺寸每边不超过 2048 像素；每包总解码像素不超过 16,777,216。所有动作合计最多 120 帧，每帧 40–10000 毫秒，一个动作总时长不超过 30 秒。ZIP 和解压后总大小均不超过 64 MiB，条目最多 256 个；配置和每份说明文件最多 64 KiB。最多导入 32 个自定义角色。

图片路径使用英文、数字、下划线、短横线及 `/` 子目录，以 .png 结尾。说明文件只接受根目录的 README.md、LICENSE.txt、LICENSE.md、SOURCE.md。不接受绝对路径、`..`、重复路径、链接、可执行文件或脚本。

安装前完整检查到临时目录，失败清理临时内容，原角色和选择保持。编号重复时不会覆盖，可以改 id 后导入。下次启动时无法读取的自定义包会跳过，内置角色继续可用；找不到已选包时回到小猫。

## 移除与恢复

移除后的完整目录保存在 `%LOCALAPPDATA%\CutePet\Characters\.removed\`。需要恢复时先退出桌宠，将归档目录移回 Characters 下，并将目录名改为 character.json 中的原 id；避免与已存在目录重名，然后重启。也可以在移除前导出 ZIP，之后重新导入。程序不会自动删除归档。
