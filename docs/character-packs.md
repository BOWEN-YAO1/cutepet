# 角色包与自定义角色（0.13.0）

日期：2026-10-02。角色包包含图片、动作和来源说明；程序统一处理额度、点击、眨眼、拖动、大小与窗口位置。不需要为每个图片角色修改主程序。

## 直接使用

右键桌宠或托盘 → **管理 / 导入角色…**。

- **导入 PNG / 角色包…**：选择一张 PNG，或 ZIP 角色包。导入成功后立即使用；PNG 的文件名作为角色名。
- **使用此角色**：将列表中预览的角色用于桌宠，选择立即保存。
- **播放动作**：在下拉框选择待机、眨眼、打招呼、低额度、张望、歪头或开心、召唤、坐姿、起身、召唤小云、坐姿眨眼 / 挥手 / 微笑，再播放所选角色自己的动作；下拉框只列出该包提供的动作。预览不消耗额度。
- **导出…**：保存可分享的 ZIP，包含配置、引用的图片和来源 / 许可说明。分享前确认自己的素材使用权限。
- **移除**：只移除自定义角色，保留本地归档。正在使用的角色移除后回到小猫。

小猫和洛天依始终内置可选，不能移除。单张图片不会自动生成挥手、眨眼等新姿态；它只有一个待机帧，默认仍有轻微浮动。缺少可选动作时回到待机。

导入的素材复制到 `%LOCALAPPDATA%\CutePet\Characters\<id>\`，不会上传，也不依赖原 ZIP / PNG 的路径。角色选择写入同目录上一层的 settings.json；旧版的 Character 选择自动迁移，缩放、额度条方向、锁定和其他偏好继续保留。修改已安装包后，重启或重新打开管理窗口刷新资源；暂不提供监视文件变化的实时热加载。

## 包结构

ZIP 根目录必须直接包含 character.json，不要把整个外层文件夹一并压进去。

0.36.0 起可在 `character.json` 中添加可选 `dialogue` 字段，让角色携带自己的情境台词。导入 / 导出会保留台词，旧包仍使用通用回应；支持的事件、限制与例子见 [角色台词](dialogue.md)。

```text
my-pet.cutepet.zip
├── character.json
├── idle.png
├── blink.png
├── greeting-1.png
├── greeting-2.png
├── low.png
├── SOURCE.md       可选，来源说明
└── LICENSE.txt     可选，素材许可证
```

动画图片也可以放在 `frames/` 等子目录。普通动作帧画布尺寸必须相同，推荐透明背景；0.33 起左右图集帧可用单独但彼此一致的区域大小；人物大小、脚底和头部基准需要在素材中保持对齐，程序不会自动修正姿势偏移。

仓库的 `examples/character-pack/` 是可以直接压缩导入的完整小猫示例，采用 GPL v3 素材。修改 id 和 name 即可创建自己的包；替换 PNG 并补充真实来源说明后再分享。内置角色导出的 id 仍为 cat / tianyi，若要导入为自定义变体，先改成新的 id，避免替换内置角色。

## 最小静态配置

```json
{
  "formatVersion": 1,
  "id": "my-pet",
  "name": "我的桌宠",
  "author": "你的名字",
  "license": "你的素材许可或来源说明",
  "float": true,
  "actions": {
    "idle": {
      "loop": true,
      "frames": [{ "image": "idle.png", "durationMs": 1000 }]
    }
  }
}
```

## 多帧动作

每个动作的 frames 可包含多张 PNG，也可以重复引用同一张，durationMs 是该帧持续的毫秒数。例如将以下动作加到 actions 对象中：

```json
"greeting": {
  "loop": false,
  "frames": [
    { "image": "greeting-1.png", "durationMs": 120 },
    { "image": "greeting-2.png", "durationMs": 180 },
    { "image": "greeting-1.png", "durationMs": 120 },
    { "image": "idle.png", "durationMs": 120 }
  ]
}
```

| 动作 | 是否必需 | loop | 触发与结束 |
|---|---|---|---|
| idle | 必需 | true | 日常循环；可以单帧或多帧 |
| blink | 可选 | false | 正常待机时定时触发；打招呼或低额度期间不打断 |
| greeting | 可选 | false | 点击时播放；再次点击重新开始，不积压队列；结束回到当前额度状态 |
| look | 可选 | false | 正常待机且指针未悬停角色时，每隔 8–16 秒尝试张望；结束回到基础状态 |
| hover | 可选 | false | 指针进入角色后停留 400 毫秒触发，一次进入最多播放一次 |
| happy | 可选 | false | 和 greeting 一起作为随机点击回应；只提供其中一个时始终播放该动作 |
| conjure | 可选 | false | 坐下前有限播放，需要 sit；结束保持坐姿 |
| sit | 可选 | true | 持续坐姿基础状态；期间不播放站姿眨眼、张望或悬停图 |
| stand | 可选 | false | 起身时有限播放，需要 sit；结束返回基础状态或最近一次点击回应 |
| summon-cloud | 可选 | false | 乘云前播放施法，需 cloud 图层；结束后云出现并移动 |
| sit-blink | 可选 | false | 坐稳时定时眨眼，需要 sit；结束回到 sit |
| sit-greeting | 可选 | false | 坐稳时点击挥手，需要 sit；结束继续坐着 |
| sit-happy | 可选 | false | 坐稳时点击或每隔 8–16 秒尝试微笑，需要 sit；结束继续坐着 |
| edge-idle | 可选 | true | 左侧贴边基础姿势，右侧自动镜像 |
| edge-peek | 可选 | false | 有限探头回应，需要 edge-idle；结束保持贴边 |
| edge-shy | 可选 | false | 左右缩回再探出，需要 edge-idle；有限播放后返回基础姿势 |
| edge-sway | 可选 | false | 左右探头轻摇，需要 edge-idle |
| edge-nod | 可选 | false | 左右探头点头，需要 edge-idle |
| edge-top-idle | 可选 | true | 上沿抓边姿势，可独立提供 |
| edge-top-peek | 可选 | false | 上沿回应，需要 edge-top-idle |
| edge-bottom-idle | 可选 | true | 下沿托腮姿势，可独立提供 |
| edge-bottom-peek | 可选 | false | 下沿回应，需要 edge-bottom-idle |
| low | 可选 | true | 新鲜有效额度低于 20% 时播放；旧数据或额度恢复后回到待机 |

待机、低额度、坐姿及贴边基础动作必须循环，其他动作必须有限播放。点击回应优先于歪头，歪头优先于张望 / 眨眼；拖动、按住鼠标或打开右键菜单时暂停自动动作触发。进入低额度状态会清除自动动作；点击回应仍能播放，结束后返回低额度。隐藏桌宠时停止帧计时器并清除临时动作，恢复后继续基础状态；切换角色清除旧动作。管理预览独立于桌宠，也没有账号连接。

0.31.0 的左右回应只轮换角色包实际提供的 edge-peek / edge-shy / edge-sway / edge-nod，顺序如表，旧包只提供 edge-peek 时仍使用原有单一回应。动作时长与姿势帧由包定义，内置运动按动作总时长归一化：edge-shy 先缩回后探出，edge-sway 双次轻摆，edge-nod 小幅上下点头。动作过程有输入保护，不在播放中追加队列；角色页也显示对应位移和轻摇预览。没有新增 PNG，依旧遵守总解码像素上限。

## 配置字段

| 字段 | 默认值 / 范围 | 用途 |
|---|---|---|
| formatVersion | 1 | 包格式版本 |
| id | 必填 | 小写字母开头，后接小写字母、数字或短横线，最长 64 字符；同一角色库内唯一 |
| name | 必填，最长 60 字符 | 菜单和管理窗口名称 |
| author | 空，最长 200 字符 | 作者说明 |
| license | 空，最长 2000 字符 | 素材许可或权利说明，不会默认套用代码 GPL |
| displayWidth | 178，范围 40–210 | 角色在基础区域内的显示宽度 |
| displayHeight | 148，范围 40–148 | 显示高度，底部对齐；图片等比例适配 |
| float | true | 是否启用轻微上下浮动，false 可保持静态位置 |
| blinkIntervalMs | 4000，范围 1000–60000 | 自动眨眼间隔；站姿使用 blink，坐姿使用 sit-blink，缺少对应动作时不触发 |
| restAfterMs | 0（不开启）；启用范围 5000–300000 | 自动坐下的无交互时间，需要 sit，受用户 AutoRest 偏好控制 |
| restDurationMs | 20000，范围 1000–300000 | 自动坐姿持续时间；坐姿点击重置自动休息计时；手动坐下持续至起身或拖动等中断 |
| cloud | 可选 | 独立云图层及大小，详见 [乘云说明](cloud-drift.md) |
| edgeAnchorX | 0，范围 0–0.5 | 左侧虚拟边缘在画布宽度中的比例；详见屏幕边缘互动说明 |
| edgeTopAnchorY | 0，范围 0–0.5 | 上沿接触线在画布高度中的比例 |
| edgeBottomAnchorY | 1，范围 0.5–1 | 下沿接触线在画布高度中的比例 |
| actions | 必须含 idle | 二十种已支持动作（含自定义 hover）及逐帧时间 |

角色大小菜单仍独立控制整体缩放，不需要修改包中的显示尺寸。动作帧最短 40 毫秒，播放器使用 40 毫秒 UI 计时器；实际调度受桌面负载影响，不保证逐帧的视频级时序。支持单独的 cloud 图层；暂不支持 GIF、APNG、多层骨骼、声音、脚本、任意自定义触发或联网下载。

## 导入限制和失败处理

PNG 文件每张不超过 8 MiB，尺寸每边不超过 2048 像素；每包总解码像素不超过 44,040,192。所有动作合计最多 120 帧，每帧 40–10000 毫秒，一个动作总时长不超过 30 秒。ZIP 和解压后总大小均不超过 64 MiB，条目最多 256 个；配置和每份说明文件最多 64 KiB。最多导入 32 个自定义角色。

图片路径使用英文、数字、下划线、短横线及 `/` 子目录，以 .png 结尾。说明文件只接受根目录的 README.md、LICENSE.txt、LICENSE.md、SOURCE.md。不接受绝对路径、`..`、重复路径、链接、可执行文件或脚本。

安装前完整检查到临时目录，失败清理临时内容，原角色和选择保持。编号重复时不会覆盖，可以改 id 后导入。下次启动时无法读取的自定义包会跳过，内置角色继续可用；找不到已选包时回到小猫。

## 移除与恢复

移除后的完整目录保存在 `%LOCALAPPDATA%\CutePet\Characters\.removed\`。需要恢复时先退出桌宠，将归档目录移回 Characters 下，并将目录名改为 character.json 中的原 id；避免与已存在目录重名，然后重启。也可以在移除前导出 ZIP，之后重新导入。程序不会自动删除归档。

## 0.33.0 左右逐帧姿势图集

支持同一 PNG 图集的区域取帧，包格式仍为 1；使用这些字段的包需要 CutePet 0.33.0 或更高版本。旧完整 PNG 动作继续兼容。示例帧：

```json
{"image":"edge-sequence-v3.png","durationMs":160,
 "region":{"x":384,"y":0,"width":384,"height":512},
 "edgeAnchorX":0.3020833333333333,"edgeAnchorY":0.568359375}
```

region 使用源 PNG 的整数像素坐标，宽高为正，必须完整位于源图内。全部左右图集区域保持相同宽高，左右动作不能混用图集视图和完整 PNG。普通图集帧的有效区域需与普通动作保持同画布。edgeAnchorX / edgeAnchorY 只用于左右图集帧，分别限定在 0–0.5 / 0–1，表示每帧两手扶边线与扶边中心高度；省略时沿用包的 X 锚点与基础帧 Y。逐帧注册使手贴稳边缘，身体的探出由姿势帧完成，不额外整体平移 / 旋转。旧非图集角色保留原有位移与轻摇。

同图集区域跨动作共享缓存，导出只带当前引用的原始 PNG，导入保留区域与锚点。原始图集与各个不同区域都保守计入 44,040,192 像素上限，重复引用不重复计数。单 PNG 8 MiB / 2048 边长、每动作 30 秒、帧 40–10000 毫秒、总 120 帧、角色 ZIP / 解压后 64 MiB 等限制不变。内置天依有八张姿势、四组回应、102 个总帧引用；27 张活跃 PNG，含区域预算 44,015,942。

角色页预览显示固定参考边缘并隐藏边缘外部分。实际桌面只裁切人物，额度窗口固定。姿势是少量不同绘制帧，不是骨骼动画；四组回应共用八张姿势，并非每组独立补绘全部动作。
