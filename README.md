# CutePet

一个计划面向 Windows 的桌面宠物，用角色动画和小面板显示 Codex 剩余额度与重置时间，并在使用后自动同步官方数据。

> 已实现独立额度读取模块、Windows 桌宠和应用主界面：额度概览、角色管理、活动与设置，保留独立额度条、自定义角色包、王座、乘云、屏幕边缘互动及托盘。当前开发原型为 0.29.0，完整桌面验收仍待完成。

## 桌宠启动

开发环境需要 Windows 和 .NET 8 SDK，安装兼容的原生 Codex CLI 并使用 ChatGPT 登录。

```powershell
dotnet build CutePet.sln
dotnet run --project src/CutePet.Desktop --no-build
```

便携开发包解压后双击 `CutePet.exe`。当前包依赖已安装的 [.NET 8 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)，不包含运行环境。桌宠会使用现有官方登录同步额度；找不到 CLI 时可右键选择 `codex.exe`，退出后重新启动生效。

手动启动会打开主界面，**概览 / 角色 / 活动 / 设置** 四页集中展示常用功能。双击托盘图标可再次打开；关闭界面后桌宠继续运行，登录 Windows 自动启动时主界面保持关闭。新版使用统一的小猫云图标。体验和扩展入口见 [主界面说明](docs/control-center.md)。

人物和额度是两个独立透明窗口，拖动人物或乘云不会带动额度。拖额度条可自由摆放，按 Esc 取消，位置重启保留；主界面设置或右键「额度条位置」可一次性放回人物的上、下、左、右。主界面也可调整大小、置顶、隐藏和退出；双击托盘图标打开主界面，点击「显示桌宠」可恢复隐藏的桌宠。升级前先退出旧实例。默认每 60 秒读取，通知或手动刷新最短间隔 10 秒。

平时额度条仅显示前两个窗口的短标签和放大的剩余百分比，例如「5h 72%」「周 48%」，去掉状态行、进度条和菜单按钮。同步失败时简略百分比显示「—」，上次数据与同步状态在详情中查看。悬停额度 350 毫秒展开详情，鼠标移开 650 毫秒后收起；鼠标移入详情可继续查看和刷新。右键或托盘「详情显示」可选择 **悬停显示 / 固定显示 / 隐藏详情**，重启保留选择。详情中也可点击「固定」或「收起」。

完整说明、打包方法与验收边界见 [桌宠窗口说明](docs/desktop-shell.md)。

右键或托盘 → **管理 / 导入角色…** 可预览、切换、导入、导出和移除角色。导入透明 PNG 即可成为静态角色；导入 ZIP 角色包可自带待机、眨眼、打招呼和低额度动作。素材复制到本机用户目录，删除原导入文件不会影响使用。移除自定义角色保留归档，内置小猫和洛天依始终可选。格式、示例与恢复方式见 [角色包说明](docs/character-packs.md)。

右键或托盘「角色选择」可切换 **小猫 / 洛天依（同人）**，立即生效、重启保留。洛天依使用 AI 生成的透明同人图，支持浮动、待机眨眼、随机左右张望、点击随机挥手 / 开心回应和低额度表情；小猫保留眨眼，并增加点击轻摇和低额度眯眼。隐藏后暂停并清除临时动作。素材记录见 [角色素材说明](docs/character-assets.md)。王座动作、自动 / 手动休息与体验步骤见 [王座休息说明](docs/throne-rest.md)。乘云功能见 [乘云飘动说明](docs/cloud-drift.md)：右键或托盘可选择“乘云去逛逛”，当前屏幕内自由活动开关重启保留，并可召回到额度旁；鼠标靠近、查看详情及打开菜单时暂停，锁定位置会禁止移动。

右键或托盘的 **角色大小 / 额度数字大小** 可分别选择 80%–200%，互不联动，重启保留。额度数字调整时，短标签和底板一起适配；悬停详情保持原大小。旧版全局大小分别作为两项的初始值，无需删除设置。

右键或托盘 **锁定位置** 禁止拖角色和额度条，重启保留，悬停和点击回应继续可用；取消勾选即可解锁。**开机启动** 默认关闭，打开后注册当前用户登录启动项，关闭只移除 CutePet 自己的条目。开关检查实际注册状态，写入失败不会声称成功。便携目录移动或更新后手动启动新版，会更新已经启用的路径。

## 额度读取原型

需要 .NET 8 SDK（开发）和兼容的原生 Codex CLI。本机已验证 `codex-cli 0.159.2`。程序复用官方 CLI 的已有 ChatGPT 登录，只查询账号状态与额度，不运行模型任务，不复制凭据。

```powershell
dotnet build CutePet.sln
dotnet run --project src/CutePet.QuotaProbe --no-build
```

持续观察并输出脱敏 JSON：

```powershell
dotnet run --project src/CutePet.QuotaProbe --no-build -- --watch --json
```

CLI 不在 PATH 时，添加 `--codex "完整路径\codex.exe"`。当前 Windows 原型不支持 `.cmd` / `.ps1` 启动器。未登录时先执行官方 `codex login`；程序不会自动打开登录或注销已有账号。

详见 [额度模块接入说明](docs/quota-reader.md) 和 [接入验证记录](docs/codex-integration-validation.md)。验证记录区分真实账号测试、模拟协议测试和待验证项。

- 已实现：角色与额度数字独立缩放，四方向布局自适应与旧设置兼容。
- 已实现：独立角色包、单张 PNG / 动画 ZIP 导入、管理预览、导出、移除归档和旧设置迁移。
- 已实现：位置锁定、默认关闭的开机启动开关、洛天依眨眼 / 挥手 / 低额度表情及动画生命周期管理。
- 已实现：天依多姿态挥手、待机张望、随机点击回应及全动作预览。
- 已实现：天依王座休息流程、自动休息开关、手动坐下 / 起身与管理预览。
